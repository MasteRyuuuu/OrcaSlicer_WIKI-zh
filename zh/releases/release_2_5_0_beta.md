# V2.5.0 Beta

> [!NOTE]
> 中文版翻译了版本概述和每一项更新的标题。每项更新的详细说明、贡献者和截图，请查看[英文原文](https://github.com/OrcaSlicer/OrcaSlicer/wiki/release_2_5_0_beta)。

这是 OrcaSlicer V2.5.0 Beta。它在 Alpha 的基础上带来了新功能、更快的打印和切片，并修复了 Alpha 以来报告的许多问题。**工具头碰撞体积**让打印机配置可以标出热床上方的热床夹子、工具头停靠座和其他障碍物，使自动摆放、Brim、大多数支撑和空驶都能避开它们。每次打印的空驶都**更短**，通常无需开启任何选项就能节省打印时间；**均匀圆滑的填充拐角**让平滑后的稀疏填充打印得更快；在细节丰富的模型上**切片速度最高提升一倍**，在包含数千个零件的对象上更是快了许多倍。**半透明耗材丝**现在在预览中呈现透明效果。此外，Beta 修复了 Windows 上的网格布尔运算、Apple 芯片 Mac 上的随机崩溃以及退出时卡住的问题。

**注意：** 这是用于测试的 Beta 版本。请备份你在意的项目和配置，并在 GitHub 上报告遇到的任何问题。
