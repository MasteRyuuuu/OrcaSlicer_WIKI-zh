# V2.5.0 RC

> [!NOTE]
> 中文版翻译了版本概述和每一项更新的标题。每项更新的详细说明、贡献者和截图，请查看[英文原文](https://github.com/OrcaSlicer/OrcaSlicer/wiki/release_2_5_0_rc)。

OrcaSlicer 2.5.0 即将完成，这个候选版本让你可以在正式版之前抢先试用。2.5.0 是 OrcaSlicer 迄今最大的一次更新：你可以用 **Python 插件**添加功能、在**传送带打印机**上打印、把已装载的耗材丝混合出新颜色、给表面加上真实的立体纹理，以及在实验性的**设计选项卡**中设计参数化零件。本版本还支持**拓竹 H2C 和 A2L**，启动、切片和导出也明显更快。[Alpha]({{L1}}) 和 [Beta]({{L2}}) 的发布说明详细介绍了所有新内容。

🧩 **试试插件吧！** 社区已经在 [Orca Cloud 插件中心]({{L3}})创建并分享了大量插件，去看看吧：说不定就有你一直缺少的那个工具。插件可以添加一键工具、微调层和 G-code 的生成结果，或者为 OrcaSlicer 带来全新的面板。从主菜单打开**插件**，用你的 Orca Cloud 账户订阅喜欢的插件，OrcaSlicer 就会安装它们，并在作者改进插件时提供更新。插件在联网、启动其他程序或访问 OrcaSlicer 数据文件夹以外的内容之前，总会先征得你的许可。自己有想法？[插件开发指南]({{L4}})能帮你入门，把插件发布到插件中心后，所有人都能使用。

感谢每一位测试 Beta 版的用户！这个候选版本修复了你们报告的许多错误和崩溃。切片重新可以一次点击就开始，多处崩溃也已消除，包括设备选项卡中的崩溃和打开某些项目时的崩溃。重启后，OrcaSlicer 会重新连接你上次使用的拓竹打印机，并保留从 AMS 同步的耗材丝。在拓竹 H2D、X2D 和 H2C 上，每种耗材丝现在都会分配到它实际装载的喷嘴。在使用 Wayland 的 Linux 上，鼠标断开或休眠时 OrcaSlicer 不再退出，闪电填充也不再让某些模型的切片卡住。

**如果你使用多种耗材丝打印，请注意：** 在**按走线类型指定耗材丝**中，保持**默认**的走线类型现在总是用对象自己的耗材丝打印。以前，为填充或顶面、底面选择一种耗材丝，可能会悄悄地把其他保持默认的走线类型也切换成这种耗材丝。如果旧项目依赖这种行为，请把这些走线类型设置为你想要的耗材丝。

**注意：** 这是 2.5.0 的候选版本，已经足够稳定，可以日常使用。遇到任何问题，请在 [GitHub]({{L5}}) 上报告。
