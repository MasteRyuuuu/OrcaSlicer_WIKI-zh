# V2.5.0

> [!NOTE]
> 中文版翻译了版本概述和每一项更新的标题。每项更新的详细说明、贡献者和截图，请查看[英文原文](https://github.com/OrcaSlicer/OrcaSlicer/wiki/release_2_5_0)。

**OrcaSlicer 2.5.0 来了，这是 OrcaSlicer 历史上最大的一次更新**，由 180 多位贡献者的近 1,300 个拉取请求构建而成。现在你可以用 **Python 插件**添加功能、在**传送带打印机**上打印、用**颜色混合**把已装载的耗材丝混合出新颜色、用**纹理置换**给表面加上真实的立体纹理、在实验性的**设计选项卡**中设计参数化零件，以及在 **IDEX 和 IQEX 打印机**上一次打印二到四个零件。**工具头碰撞体积**让自动摆放、Brim 和空驶避开热床夹子、工具头停靠座和其他障碍物。更智能的空驶规划无需开启任何选项就能减少不必要的移动，OrcaSlicer 的启动、切片和导出也明显更快。本版本还支持**拓竹 H2C 和 A2L**，H2D 和 X2D 上可以混用不同尺寸的喷嘴，并带来了新的**快捷面板**、精确接缝修改器、新的填充选项以及数百项修复。

**注意：** 本版本包含 2.5.0 [Alpha]({{L1}})、[Beta]({{L2}}) 和[候选版本]({{L3}}) 中的全部内容；如果你是从 2.4 升级，这些版本的发布说明详细介绍了所有新内容。下面的说明只涵盖候选版本之后的改动。

🧩 **试试插件吧！** 社区已经在 [Orca Cloud 插件中心]({{L4}})创建并分享了大量插件，去看看吧：说不定就有你一直缺少的那个工具。插件可以添加一键工具、微调层和 G-code 的生成结果，或者为 OrcaSlicer 带来全新的面板。从主菜单打开**插件**，用你的 Orca Cloud 账户订阅喜欢的插件，OrcaSlicer 就会安装它们，并在作者改进插件时提供更新。插件权限让你控制插件能否联网、启动其他程序或访问 OrcaSlicer 数据文件夹以外的内容，新的**权限**选项卡会显示每个插件被允许做什么。权限并不是沙箱，所以请只安装你信任的插件。自己有想法？[插件开发指南]({{L5}})能帮你入门，把插件发布到插件中心后，所有人都能使用。

感谢每一位测试候选版本的用户！本版本修复了你们报告的阻碍性问题。开启**翘边降速**时，桥接重新以桥接速度打印；使用 Arachne 和圆弧拟合时，斜拼接缝不再显示为条带；Klipper 打印机也不再在每次换工具头时停在擦拭塔上方。网格布尔运算、耗材丝同步以及耗材丝数量少于打印机工具头数量的项目不再崩溃，在 Linux 上于设置搜索中按 Esc 也不再让 OrcaSlicer 卡死。在从未同步过的电脑上可以下载 Orca Cloud 预设，设备选项卡中的自定义摄像头源也回来了。Windows 版本现在还使用 OrcaSlicer 自己的代码签名证书进行签名。

**如果你从 2.4 升级，有两项改动需要检查：**

- **拓竹工艺预设默认使用网格填充。** 2.5.0 与 BambuStudio 的配置同步（[15851]({{L6}})）把拓竹工艺预设的默认**稀疏填充图案**从交叉层叠改成了网格。没有自行设置图案的预设现在都使用网格，基于它们的你的预设也是如此。要继续使用交叉层叠，请在你的工艺预设中设置它。
- **保持"默认"的走线类型使用对象的耗材丝。** 在**按走线类型指定耗材丝**中，保持**默认**的走线类型现在总是用对象自己的耗材丝打印（[17058]({{L7}})）。以前，为填充或顶面、底面选择一种耗材丝，可能会悄悄地把其他保持默认的走线类型也切换成这种耗材丝。如果某个项目依赖这种行为，请把这些走线类型设置为你想要的耗材丝。
