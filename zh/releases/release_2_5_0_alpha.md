# V2.5.0 Alpha

> [!NOTE]
> 中文版翻译了版本概述和每一项更新的标题。每项更新的详细说明、贡献者和截图，请查看[英文原文](https://github.com/OrcaSlicer/OrcaSlicer/wiki/release_2_5_0_alpha)。

这是 OrcaSlicer V2.5.0 Alpha，**OrcaSlicer 历史上功能最丰富的一个版本**，由 140 多位贡献者的 950 多个拉取请求构建而成。现在你可以用 **Python 插件**扩展切片软件、在**传送带打印机**上打印、在实验性的**设计选项卡**中设计参数化零件、用**颜色混合**把已装载的耗材丝混合出新颜色、用**纹理置换**给表面加上真实的立体纹理，以及在 **IDEX 和 IQEX 打印机**上一次打印二到四个零件。此外还有新的**快捷面板**、对**拓竹 H2C 和 A2L** 的支持、H2D 和 X2D 上的混合喷嘴尺寸、大幅加快的启动、切片和 G-code 导出速度、精确接缝修改器、新的填充选项，以及数百项修复。

**注意：** 这是用于测试的 Alpha 版本。其中有几项新功能是实验性的，在正式版之前可能会改变，所以请备份你在意的项目和配置，并在 GitHub 上报告遇到的任何问题。

## 🧩 插件 [[en:🧩 Plugins]]

OrcaSlicer 2.5.0 推出了 **Python 插件**，这是一种受支持的方式，让你无需维护一个分支版本就能给切片软件添加自己的功能。插件可以添加一键运行的脚本，介入切片过程来改造层或改写 G-code，添加自己的选项卡或停靠面板，或者对打印完成之类的事件做出响应。从主菜单打开**插件**，即可从电脑上的文件或从 Orca Cloud 安装插件；插件在访问 OrcaSlicer 数据文件夹以外的内容、联网或启动其他程序之前，必须征得你的许可。插件系统是新推出的，其 API 仍可能改变，非常欢迎用户和插件作者提供反馈。[插件入门]({{L1}}) · [插件开发指南]({{L2}})

## 🏭 传送带打印 [[en:🏭 Belt Printing]]

本版本增加了对传送带打印机的支持——这类传送带式（"无限 Z 轴"）机器的龙门倾斜架在移动的传送带上方，通常为 45°。由于传送带会把打印好的材料从喷嘴下带走，零件可以比机器更长，一排零件也可以一个接一个地打印，无需清理打印板。本版本附带了 Printcepts BabyBelt Pro 和 IdeaFormer IR3 V2 的现成配置，以及一个通用传送带打印机配置，你可以把它改用于 CR-30 系列等其他机器。要开始使用，只需添加其中一台打印机并照常切片；传送带相关选项位于打印机设置 → 基本信息 → 传送带打印机中，在高级及以上模式中显示。[传送带打印指南]({{L91}})介绍了设置方法、传送带切片的原理，以及工作流程中会有哪些变化。

## 👯 面向 IDEX 和 IQEX 的 iXex 并行打印 [[en:👯 iXex Parallel Printing for IDEX & IQEX]]

OrcaSlicer 现在可以把拥有独立滑车的打印机作为并行打印机来驱动。在 IDEX（一个龙门上有两个工具头）、双龙门机器或 IQEX（两个龙门上各有两个工具头）上，每个工作中的滑车同时打印零件的一份副本——直接复制或镜像——因此一次打印就能得到二到四个零件。OrcaSlicer 只需对零件切片一次，就能准确显示每个滑车会打印在哪里，让零件避开滑车可能相撞的区域，并告诉固件运行哪种模式。本版本附带了 Vivedino Xplorer 的现成配置（IDEX、双龙门和 IQEX，以及单头型号），其他任何 IDEX 或 IQEX 打印机也都可以在其打印机设置中完成配置。

- **IDEX 和 IQEX 打印机的并行打印**（[13086]({{L128}})）

## ✏️ 设计选项卡（早期预览） [[en:✏️ Design Tab (Early Preview)]]

设计选项卡是 OrcaSlicer 内一个新的、实验性的 CAD 工作区。绘制轮廓草图、添加约束和尺寸、把它变成实体，然后提交到盘——无需再借助其他 CAD 程序和 STL 来回周转。你构建的是可编辑的特征历史而不是网格，并且它保存在 3MF 中，所以你可以重新打开项目、修改某个尺寸，让整个零件随之重建。该选项卡默认关闭：在偏好设置 → 常规 → 特性中勾选 **CAD 功能（实验性）** 并重启 OrcaSlicer 即可试用。它仍在积极开发中，所以预计各版本之间会有变化，请为你在意的项目保留备份。[Wiki]({{L130}})

- **设计选项卡：以草图为先的参数化 CAD**（[15238]({{L131}})、[15762]({{L132}})）
- **设计选项卡：文字和旋转特征、更清晰的渲染和更顺畅的工作流程**（[16019]({{L134}})、[16158]({{L135}})）
