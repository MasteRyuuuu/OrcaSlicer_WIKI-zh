# V2.4.0 Beta

> [!NOTE]
> 中文版翻译了版本概述和每一项更新的标题。每项更新的详细说明、贡献者和截图，请查看[英文原文](https://github.com/OrcaSlicer/OrcaSlicer/wiki/release_2_4_0_beta)。

这是 OrcaSlicer V2.4.0 Beta。本版本在提升稳定性、速度和打印质量，以及改进界面和打印机支持方面投入了大量精力。尤其是桥接，在 @ianalexis、@kisslorand 等许多人的努力下有了很大改进；@RF47 带来的新的真实感渲染选项，让你的模型直接在 OrcaSlicer 中就显得非常漂亮。

多材料用户也有好消息：按特征分配耗材丝得到了大幅升级，可以实现更有创意的打印。想过用 TPU 打印外墙、其余部分用 PLA 吗？现在可以了——详情见下文。

**注意：** 本版本包含 2.4.0 Alpha 中的所有内容——Orca Cloud、Z 层抗锯齿（ZAA）、机器输入整形、优化的螺旋体填充，以及重新设计的打印机选择对话框。这些内容的详情请参见 [2.4.0 Alpha 发布说明]({{L1}})。

### 桥接 [[en:Bridging]]

桥接的一次重大全面改进——专用的桥接线宽、更智能的桥接角度控制，以及针对外部桥接、沉孔桥接和修改器内桥接的一批可靠性修复。

- **专用的桥接线宽，让桥接更结实、粘合更好**（[11255]({{L17}})）
- **相对桥接方向，以及让桥接/熨烫角度与模型对齐**（[12055]({{L18}})）
- **在复杂几何上更可靠的外部桥接**（[12568]({{L19}})）
- **修复使用"额外桥接层"时顶面上多余的桥接填充**（[13860]({{L20}})）
- **修复沉孔的桥接**（[13956]({{L21}})）
- **遵循修改器中的桥接速度**（[13971]({{L22}})）
