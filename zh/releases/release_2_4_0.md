# V2.4.0

> [!NOTE]
> 中文版翻译了版本概述和每一项更新的标题。每项更新的详细说明、贡献者和截图，请查看[英文原文](https://github.com/OrcaSlicer/OrcaSlicer/wiki/release_2_4_0)。

这是 OrcaSlicer V2.4.0 版本。它的重点是错误修复、更顺畅的 Orca Cloud 体验，以及新功能，例如把切片好的任务以打包的 3MF 形式发送到打印机。在 Orca Cloud 方面，现在离线时也能保持登录，同步不会再覆盖在本地重新创建的预设，已订阅的预设有可用更新时会弹出通知。其他新增内容包括 Windows 上新的 Microsoft Store 安装渠道（提交目前正在审核中）、更快的从切片到预览的处理（在 Klipper 风格的打印机上提升最大）、裙边生成的全面改进，以及耗材丝列表的易用性改进——此外还有一大批错误修复（树状支撑、校准、运动能力设置以及 Linux/Flatpak）和更新的翻译，包括中文。

**注意：** 本版本包含 2.4.0 Alpha 和 2.4.0 Beta 中的所有内容——Orca Cloud、Z 层抗锯齿（ZAA）、机器输入整形、优化的螺旋体填充、重新设计的打印机选择对话框、真实感视图渲染、桥接的全面改进、扩展的按特征分配耗材丝、故障排查中心、原生的 Moonraker 和 3DPrinterOS 主机，以及 Creality K 系列支持。

这些内容的详情请参见 [2.4.0 Alpha]({{L1}}) 和 [2.4.0 Beta]({{L2}}) 的发布说明。

## 🌊 新功能与改进 [[en:🌊 New Features & Improvements]]

- **把切片好的任务以打包的 3MF 形式发送到打印机**（[14238]({{L3}})）
- **Windows 上的 Microsoft Store（MSIX）安装渠道**（[14142]({{L4}})）
- **离线时保持 Orca Cloud 登录**（[14235]({{L5}})）
- **耗材丝列表改进：数量标记、自动滚动和自动展开**（[14158]({{L6}})）
- **在折叠的打印机标题栏上显示当前打印机名称**（[14148]({{L7}})）
- **通过缓存 G-code 后处理模式加快切片**（[14166]({{L8}})）
- **已订阅的预设有更新时发出通知**（[14121]({{L9}})）
- **从侧边栏的开发者按钮打开故障排查中心**（[14178]({{L10}})）
- **允许让下沉的对象落板**（[14243]({{L11}})）
- **裙边全面改进：能感知碰撞的逐对象裙边，以及正确的"先裙边后 Brim"顺序**（[14130]({{L12}})）
- **3D 视图中更平滑的对象着色**（[14080]({{L13}})）
