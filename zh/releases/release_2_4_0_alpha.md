# V2.4.0 Alpha

> [!NOTE]
> 中文版翻译了版本概述和每一项更新的标题。每项更新的详细说明、贡献者和截图，请查看[英文原文](https://github.com/OrcaSlicer/OrcaSlicer/wiki/release_2_4_0_alpha)。

这是 OrcaSlicer V2.4.0 Alpha 版本。最重要的功能是 **Orca Cloud**——位于 cloud.orcaslicer.com 的全新集中式平台，用于配置同步、预设包分享和社区发现。本版本还推出了让顶面更平滑的 **Z 层抗锯齿（ZAA）**、专家用户模式、Linux 原生 Wayland 支持、机器输入整形、优化的螺旋体填充、Prusa 风格的合并 Brim、重新设计的打印机选择对话框，以及大量错误修复和配置更新。

**注意：** 已知问题请查看 #13828。

## ☁️ Orca Cloud [[en:☁️ Orca Cloud]]

Orca Cloud 现已在 [cloud.orcaslicer.com]({{L1}}) 上线——一个把你的 3D 打印工作流程搬到线上的集中式平台。

它让你的打印机、耗材丝和工艺配置在你使用的每台电脑之间保持同步，让你与社区分享精心调校的预设包，并帮助你发现世界各地创客们创建的配置。

可以把它看作连接你的切片软件、你的配置以及更广阔的 OrcaSlicer 生态系统的纽带——不必再在电脑之间手动复制配置文件，也不必在论坛里四处寻找合适的配置。

**注意：** Orca Cloud 是可选的。本地配置和现有的 OrcaSlicer 工作流程照常工作。不登录 Orca Cloud 也可以继续使用 OrcaSlicer。

**开放的生态系统：** Orca Cloud 是我们打造开放 3D 打印生态系统的长期愿景的一部分。我们希望 OrcaSlicer 通过共享配置、更好的兼容性数据和更顺畅的工作流程，把用户、贡献者、打印机厂商、耗材丝厂商以及软硬件合作伙伴连接起来。我们欢迎用户、创客、厂商和合作伙伴加入、集成并与我们合作，共同建设一个惠及整个社区和更广泛 3D 打印行业的生态系统。

这只是一个开始。我们为 Orca Cloud 和更广泛的 OrcaSlicer 生态系统规划了更多功能。

Orca Cloud 的设计重视隐私。数据目前托管在美国。未来我们计划增加更多区域服务器，并允许用户选择偏好的数据中心位置，以满足性能、数据驻留和隐私方面的需求。
