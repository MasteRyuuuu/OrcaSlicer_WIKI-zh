# V2.4.1

> [!NOTE]
> 中文版翻译了版本概述和每一项更新的标题。每项更新的详细说明、贡献者和截图，请查看[英文原文](https://github.com/OrcaSlicer/OrcaSlicer/wiki/release_2_4_1)。

这是 OrcaSlicer V2.4.1 版本——在 2.4.0 基础上的维护更新，核心是对配置和预设进行了大范围修复：恢复了 Orca 耗材丝库和耗材丝选择对话框中丢失或被错误归类的耗材丝，消除了重复的配置设置 ID，修正了有歧义的 AMS 耗材丝匹配，并改进了重命名预设和继承预设的解析方式。其他改动包括原生的 Windows ARM64 版本、新的最低腔体温度字段，以及重写的裙边和 Brim 生成器（修复了 2.4.0 中逐件/顺序打印时会重复打印裙边的回归问题），此外还修复了绒毛表面、AMS 同步顺序、CrealityPrint 主机以及 Linux Wayland 渲染方面的问题。本版本还新增了 Snapmaker U1 喷嘴配置、Elegoo Centauri 2 支持，并更新了翻译目录。
