# 版本发布

OrcaSlicer 各版本的发布说明，最新的排在最前。选择一个版本即可阅读完整的更新日志。

## 历史版本

> [!NOTE]
> 正式版包含其之前 Alpha 和 Beta 版本中的所有功能，但正式版的更新日志只列出自上一个正式版以来的变化——不会重复那些 Alpha 和 Beta 功能。  
> 要查看两个正式版之间的所有新内容，请同时阅读相应的 Alpha 和 Beta 发布说明。

> [!TIP]
> 中文版的各版本页面翻译了版本概述和每一项更新的标题；每一项的详细说明请查看英文原文。

- **[V2.5.0 Alpha]({{L1}})**——迄今功能最丰富的版本：Python 插件、传送带打印、实验性的设计选项卡、颜色混合、纹理置换，以及 IDEX/IQEX 并行打印。
- **[V2.4.2]({{L2}})**——维护更新，重点是更可靠的配置、云同步和打印机连接，并修复了几处崩溃。
- **[V2.4.1]({{L3}})**——维护更新，包含大范围的配置和预设修复、原生 Windows ARM64 版本，以及重写的裙边和 Brim 生成器。
- **[V2.4.0]({{L4}})**——错误修复、更顺畅的 Orca Cloud 体验，以及把切片好的任务以打包的 3MF 形式发送到打印机的功能。
    - **[V2.4.0 Beta]({{L5}})**——在稳定性、速度和打印质量方面的工作——大幅改进的桥接，以及新的真实感渲染选项。
    - **[V2.4.0 Alpha]({{L6}})**——推出 Orca Cloud（配置同步和分享）、Z 层抗锯齿、专家用户模式，以及 Linux 原生 Wayland 支持。
