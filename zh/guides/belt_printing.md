# 传送带打印

传送带打印机（也叫输送带打印机或"无限 Z 轴"打印机）用一条可移动的传送带取代固定的热床，并让龙门架倾斜架在传送带上方，通常倾斜 45°。由于传送带会把打印好的材料从喷嘴下方带走，零件可以比机器本身更长，而且可以连续打印一系列零件，中间无需清理打印床。

OrcaSlicer 通过专门的传送带打印机模式支持这类机器，Printcepts BabyBelt Pro、IdeaFormer IR3 V2 以及 CR-30 类机器都在使用。本指南介绍这种模式的工作原理，以及你的工作流程会有哪些变化。各个选项的说明见[传送带打印机]({{L1}})和[机器坐标系变换]({{L2}})。

{{T1}}

## 传送带打印机有何不同

切片软件通常假定打印床位于 XY 平面、各层沿 Z 方向堆叠。传送带打印机在这两方面都不同：

- **层是倾斜的。** 喷嘴在倾斜龙门所在的平面内移动，因此每一层都是一个斜面：从传送带上开始，沿传送带前进的方向向上延伸。
- **传送带本身是一根轴。** 驱动传送带前进的电机是打印机的 Z 轴，龙门的高度方向是 Y 轴，所以"打印床"位于机器的 XZ 平面内，理论上无限长。

{{I1}}

## 设置传送带打印机

要启用传送带模式，请在 **打印机设置 → 基本信息 → 传送带打印机** 中勾选[启用传送带打印]({{L3}})。只有设置模式为 **高级** 或更高时才会显示这一组选项。关闭该选项时，OrcaSlicer 使用标准的打印行为。

{{I2}}

### 入门配置

| 打印机 | 厂商 | 喷嘴 | 工艺 | 耗材 |
| --- | --- | --- | --- | --- |
| Generic Belt Printer | Custom | 0.2、0.4、0.6、0.8 | 0.20mm Standard、0.12mm Fine | 耗材库 |
| BabyBelt Pro | Printcepts | 0.4 | 0.20mm Standard | Generic PLA、Generic PETG、eSUN PLA |
| IdeaFormer IR3 V2 | IdeaFormer | 0.4 | 0.20mm Standard | Generic PLA、Generic PETG、eSUN PLA |

### 列表中没有的打印机

1. 从 **Custom** 厂商下添加 **Generic Belt Printer**。
2. 在[可打印空间]({{L4}})中，按你的传送带设置可打印区域：**X** 是横跨传送带的宽度，**Y** 是作为一个盘显示的传送带长度。
3. 把[可打印高度]({{L5}})设为龙门下方的净空高度。在传送带打印机上，它限制的是零件高出传送带的高度，而不是零件沿传送带方向的长度。
4. 按你的机器核对[传送带倾斜]({{L6}})角度，然后保存配置。
5. 填入机器的[起始和结束 G-code]({{L7}})以及[运动限制]({{L8}})，再针对你的机器调整配置。

> [!TIP]
> 传送带相关选项可以在自定义 G-code 中作为[占位符]({{L9}})使用。例如 BabyBelt Pro 的配置就通过 `PRINT_START ANGLE=[belt_slice_rotation_angle] ...` 把倾斜角度传给起始宏。

> [!WARNING]
> 起始、结束及其他自定义 G-code 会原样写入文件，不会被旋转或重新映射，所以请按机器坐标编写：Y 是龙门，Z 是传送带。

## OrcaSlicer 如何为传送带切片

OrcaSlicer 沿用现有的切片引擎：切片前先变换模型，切片后再变换生成的工具路径。

```mermaid
flowchart LR
    A[传送带上的模型] --> B[1. 切片前旋转]
    B --> C[2. 切片]
    C --> D[3. 支撑和 Brim]
    D --> E[4. 反向变换]
    E --> F[5. 机器坐标系]
    F --> G[G-code]
```

### 1. 切片前旋转

切片前，模型会按[传送带倾斜]({{L10}})角度旋转。把旋转后的模型切成水平层，得到的就是相对于原始模型倾斜的层。这次旋转不会改变模型的形状和尺寸。

### 2. 切片

旋转后的模型按标准流程切片，因此墙、填充、接缝、熨烫、涂色以及大多数其他功能在传送带上都能正常工作，无需专门的传送带设置。

### 3. 支撑和 Brim

在旋转后的坐标系中，传送带是一个倾斜平面，而不是 Z = 0 平面。支撑和 Brim 都是相对于这个平面生成的：

- 普通支撑、树状支撑和有机支撑都终止于传送带表面，传送带以下不会生成任何东西。在零件前端的悬垂下方，支撑会在零件首次接触传送带之前就落到传送带上，所以支撑可能比零件本身更早开始打印。
- Brim 打印在传送带上，每一层贡献一条带状区域。

### 4. 反向变换

写出工具路径时，每个点都会被旋转回模型在"准备"中摆放时的坐标系，所以下一步拿到的就是"准备"中显示的坐标。

### 5. 机器坐标系

固件不会考虑龙门的倾斜，因此 OrcaSlicer 分两步把坐标换算成所需的电机位置：

1. [G-code 轴重映射]({{L11}})交换各轴。在传送带配置中，高出传送带的高度变为机器的 Y，沿传送带的位置变为机器的 Z，X 方向取反。
2. [机器坐标系倾斜]({{L12}})缩放龙门坐标并平移传送带坐标，使模型中竖直的墙打印出来也是竖直的。

## 使用传送带打印机

### 放置和排列零件

在"准备"中，盘代表传送带表面，以平铺方式显示。X 横跨传送带，Y 沿传送带方向，Z 是高出传送带的高度，所以零件的放置和朝向与其他打印机一样。最靠近 Y = 0 的零件最先打印。

{{I3}}

- 启用[无限 Y 轴]({{L13}})后，零件可以沿 Y 方向超出显示的盘。
- 零件必须能放进传送带的宽度，高度也必须能放进龙门下方（[可打印高度]({{L14}})）。
- [自动摆放]({{L15}})会从最先打印的那一端开始放置零件。它会把使用同一种耗材的零件归在一起，让每次更换耗材只发生一次，并为 Brim 和[传送带冲刷塔]({{L16}})留出空间。

> [!TIP]
> 零件朝向对悬垂的影响与平面热床不同。每一层都贴着上一层打印，从零件最先打印的一端向最后打印的一端推进。朝传送带后方伸出的悬垂是打印在已有材料上的；而零件前端的悬垂则从半空中开始，需要支撑。

### 首层

在平面热床上，首层就是第一个切片。而在传送带上，每个倾斜的层都沿一条窄带与传送带接触，所以"首层"是沿传送带表面、贯穿整个打印件的一条带状区域。

OrcaSlicer 会对这条带内的挤出应用首层的速度、加速度、抖动和温度，这条带的厚度为一个[首层层高]({{L17}})。按层数计数的设置，包括[不开启冷却]({{L18}})的层数，改为按传送带表面以上这种厚度的带状区域计数。

### Brim

每一层只沿一条线与传送带接触，因此 [Brim]({{L19}}) 比在平面热床上更有用。有三个选项是传送带打印机专用的：

{{I4}}

- [前缘长度]({{L20}})让 Brim 向零件前方延伸，把前缘锚定在已经附着在传送带上的材料上。
- [额外宽度]({{L21}})让 Brim 在横跨传送带的方向上加宽。
- [仅前缘]({{L22}}) Brim 类型把 Brim 限制在零件首次接触传送带的区域。

### 支撑

所有[支撑类型]({{L23}})都可以使用，并终止于传送带表面。[绘制的支撑]({{L24}})和[绘制的接缝]({{L25}})会跟随模型做同样的旋转。

### 多色打印

标准的[擦拭塔]({{L26}})无法在传送带上打印，取而代之的是[传送带冲刷塔]({{L27}})：OrcaSlicer 会在传送带远端边缘、零件旁边添加一个细长的对象，每次更换耗材时都把材料冲刷到这个对象里。

{{I5}}

### 预览

预览以模型坐标系显示工具路径，所以零件按设计时的样子直立显示。如果想看写入 G-code 的坐标，可在预览画布的视图菜单（工具栏中的眼睛图标）中启用 **显示原始 G-code（仅传送带）**，或按 `B` 键。这时各层会像机器实际打印时那样沿传送带轴排列。这只改变预览，导出的 G-code 不受影响。

### 校准

- 在传送带打印机上，[温度塔]({{L28}})对话框提供 **测试模型** 选项：**标准** 或 **悬垂**。
- 对于[压力提前]({{L29}})，传送带打印机上只启用 **PA 塔** 方法。

## 不可用的功能

有些功能与传送带打印不兼容，或者会导致不合适的传送带运动。OrcaSlicer 会在设置中禁用这些功能，或在启用时阻止切片。

| 功能 | 在传送带打印机上 |
| --- | --- |
| [裙边]({{L30}}) | 禁用，不生成裙边。 |
| [筏层]({{L31}}) | 设置了筏层层数时阻止切片。 |
| 风挡 | 启用时阻止切片。 |
| [擦拭塔]({{L32}}) | 从不生成。请使用[传送带冲刷塔]({{L33}})。 |
| [圆弧拟合]({{L34}}) | 禁用。机器坐标系变换会把圆变成椭圆，而 G2/G3 无法表示椭圆。 |
| [斜拼接缝]({{L35}}) | 禁用。斜拼会从上一层内部开始。 |
| 带 Brim 的[旋转花瓶]({{L36}}) | 与传送带 Brim 不兼容，因为传送带 Brim 会跨层延伸到 Z = 0 之外。 |
| [Z 抬升]({{L37}}) | 在传送带配置中设为 0，因为从倾斜的层上抬起需要移动传送带，这在大多数传送带打印机上会引发问题。 |
| Brim 类型"自动""圆盘"和"绘制" | 按外侧 Brim 打印。见 [Brim]({{L38}})。 |
| PA 划线和 PA 图案校准 | 不可用。请使用 PA 塔。 |
