# IDEX/IQEX 并行打印

带有独立滑车的打印机可以同时打印一个零件的多个副本，每个滑车打印一个。OrcaSlicer 只为工具头 T0 切片一次，在盘上显示每个滑车将要打印的位置，让零件避开滑车可能相撞的区域，并告诉固件要运行哪种模式。

本指南介绍并行打印的工作原理、如何设置打印机以及日常如何使用。各项设置的说明见 [IDEX/IQEX 配置]({{L1}})。

## 并行打印的工作原理

在并行模式下，热床被划分为若干区域，每个激活的滑车各占一个。Span 搭档与 T0 共用 T0 的区域；在 Span 模式下，另一个龙门上角色相同的滑车共用一个区域。T0 在自己的区域（即**主区域**）中按照 OrcaSlicer 切片得到的工具路径打印。其他每个激活的滑车都由固件驱动，在各自的区域里重复这些动作：

- **复制（Copy）** 滑车打印同样的零件，运动方式与 T0 相同。
- **镜像（Mirror）** 滑车打印镜像零件，以它与 T0 区域的分界线为对称轴：与 T0 同一龙门上的滑车沿 X 镜像，另一龙门上的滑车沿 Y 镜像。

每个盘都有自己的模式，所以一个项目里可以混合使用普通盘（一次只用一个工具头打印）和复制/镜像盘。模式本身只在打印机设置中定义一次。

### 支持的布局

- **一个龙门、两到四个滑车**，例如经典的 IDEX。
- **两个龙门、各一个滑车**，即双龙门 IDEX：一张热床上方有两套独立的 XY 系统。
- **两个龙门、各两个滑车**，即 IQEX，最多可同时打印四个零件。

在每个龙门有两个滑车的双龙门打印机上，T0 和一个 Span 搭档还可以用[多种颜色]({{L2}})打印零件，同时另一个龙门对其进行复制或镜像。如果固件会以各自的偏移把每个滑车移到自己的区域，请参阅[固件管理区域]({{L3}})。

## 设置打印机

1. 在 **多材料** 页面上，把[挤出机]({{L4}})数量设为工具头数量；如果有 MMU 为某个工具头供料，则设为耗材槽位的数量（见 [MMU 与 AFC]({{L5}})）。
2. 在 **高级** 模式下，在同一页面靠下的位置启用 [IDEX/IQEX 打印机]({{L6}})。
3. 描述硬件：[龙门数量]({{L7}})、[每个龙门的工具头数]({{L8}})和[工具头 0 位置]({{L9}})。
4. 测量滑车尺寸，填写[喷嘴避让距离 X]({{L10}})（双龙门打印机还要填写[喷嘴避让距离 Y]({{L11}})）。它们决定了不能放置零件的条带区域，宁可设得宽裕一些。
5. 在[模式]({{L12}})表格中添加打印机支持的并行模式，为每个工具头指定角色，并为每种模式填写通知固件的 G-code（见[固件]({{L13}})）。

### 固件

OrcaSlicer 本身不会移动其他滑车。它会在打印机起始 G-code 之前写入当前模式的 [G-code]({{L14}})，其余的事由固件完成，所以固件必须已经具备复制和镜像模式。在并行模式下，OrcaSlicer 还会省略打印开始时切换到 T0 的换工具头命令，因此必须由模式 G-code 或起始 G-code 来选中 T0。

这段 G-code 在起始 G-code 让打印机回原点之前运行。如果你的固件需要先回原点才能切换模式，或者像 Klipper 那样在回原点时重置模式，那就让模式 G-code 只记录模式，再在起始 G-code 中回原点之后切换到该模式。起始 G-code 也可以从 `imex_mode` 变量读取当前模式。

每个滑车的起始位置也由固件决定，而且必须与 OrcaSlicer 绘制的区域一致。复制滑车与 T0 保持的距离等于它的区域与 T0 区域之间的距离——两个滑车时是半个热床；镜像滑车在 T0 位于近端时位于远端。如果固件放置滑车的方式不同，副本就不会打印在盘上显示的位置。

模式只在打印开始时设置一次，不支持在打印中途切换模式。

### MMU 与 AFC

打印机的耗材数量可以多于工具头数量，例如一台 AFC 单元的四个通道为 T0 供料，其他每个工具头各装一种耗材。这时打印机配置中每个耗材槽位各列一个挤出机，并通过 `physical_extruder_map` 把每个槽位映射到它的工具头（从 0 开始编号），从而把压力提前和温度发送给正确的工具头：

{{C1}}

这里前四个槽位都给工具头 0 供料，最后三个分别给工具头 1 到 3 供料。映射表中的条目数必须与挤出机数量完全一致，否则 OrcaSlicer 会忽略它，把每个槽位都当作独立的工具头。打印机设置中没有对应的选项，所以需要在关闭 OrcaSlicer 后，把它添加到[配置文件夹]({{L15}})中打印机预设的 JSON 文件里，或者使用已包含它的厂商配置。没有 MMU 的打印机不需要映射。

### 固件管理区域

如果固件会以各自的偏移把每个滑车从 X0 Y0 移到自己的区域（[RepRapFirmware 的复制工具]({{L16}})就可以这样做），请启用[固件管理区域]({{L17}})。这样在并行模式下，G-code 会以 T0 区域的中心作为 X0 Y0 来写出。预览显示的是平移后的 G-code，并且不绘制幽灵副本。

## 使用并行打印

### 为盘选择模式

打印机设置好后，每个盘的其他图标旁边会多出一个模式图标：

- **左键单击** 依次切换打印机的各种模式。
- **右键单击** 打开包含所有模式的菜单。

{{I1}}

新建的盘默认处于 **主（Primary）** 模式，即普通模式：任何工具头都可以打印，但一次只用一个。模式会随项目保存，修改后可以撤销。图标上的警告标记表示该盘使用的耗材数量超出了该模式能打印的数量，或使用了混合耗材；见[多色打印]({{L18}})。

### 放置零件

在并行模式下，盘上会显示每个滑车的区域。主区域正常显示，其他区域按角色着色。只需把零件放在主区域内，其他滑车会自动在各自区域打印它们。

{{I2}}

- 在镜像区域旁边，有一条避让条带标出滑车可能相撞的位置。零件和擦拭塔必须位于主区域之内、并且在主区域的避让条带之外，否则该盘无法切片。
- 对盘进行摆放时，零件会被保持在主区域内并避开避让条带。
- 可选的[安全边距]({{L19}})会在每条条带旁再画一条额外的区域，但只起提醒作用，位于其中的零件仍然可以切片。

区域大小只按激活的滑车计算，所以在某个模式中未激活的滑车会把它那部分热床让给相邻的滑车。

### 幽灵副本

每个复制和镜像滑车都会在自己的区域里显示零件的半透明**幽灵**（镜像滑车显示的是镜像后的样子），在你移动、旋转或缩放零件时，幽灵会跟着变化。把鼠标悬停在幽灵上，可以看到它使用哪个工具头和哪种耗材。当 T0 有 [Span]({{L20}}) 搭档、且另一个龙门上的两个滑车角色相同时，那个龙门只为这对滑车显示一个幽灵，颜色取其中一种耗材，而不是两种。

{{I3}}

每个滑车都使用自己工具头上的耗材打印。如果 MMU 或 AFC 为某个工具头提供多种耗材，可以单击它的幽灵来选择该滑车用哪一种打印。这一选择会随盘保存。

### 多色打印

在复制或镜像模式下，一个盘通常只使用一种耗材，因为其他滑车只能重复 T0 的动作。例外是每个龙门有两个或更多滑车的双龙门打印机：给 T0 所在龙门上的某个工具头指定 [Span]({{L21}}) 角色后，它就可以和 T0 一起用多种颜色打印零件，同时由另一个龙门进行复制或镜像。

每种颜色都必须位于 T0 或某个 Span 搭档上，每个工具头一种。同一工具头上的两种耗材（例如 MMU 的两个通道）不能在并行模式中组合使用，因为其他滑车无法跟随换料。通过图层滑块添加的耗材更换也算作颜色。

混合耗材（以交替子层混合多种耗材）完全不能在并行模式中使用。要打印它们，请把盘切换为主模式。

### 温度与压力提前

在并行模式下，每个激活的滑车在打印开始时都会获得各自耗材的压力提前值，并从第二层起使用各自耗材的温度。首层时其他滑车的加热需要在打印机起始 G-code 中完成：每个激活滑车所用耗材的 `is_extruder_used` 都为 true，所以只要起始 G-code 会加热每个用到的挤出机，就能覆盖它们。

压力提前会按照固件要求的格式写出：

| 固件 | 命令 |
|---|---|
| Klipper | `SET_PRESSURE_ADVANCE ADVANCE=... EXTRUDER=extruder1`（T0 为 `extruder`） |
| RepRapFirmware | `M572 D1 S...` |
| Marlin 2 | `M900 K... T1` |

工具头编号会原样写入命令，所以固件对挤出机的编号方式必须一致：Klipper 中为 `[extruder1]`，RepRapFirmware 中为挤出驱动 1。只有在编译时启用了 `DISTINCT_E_FACTORS`，Marlin 才会为每个挤出机保存单独的值；否则包括 T0 在内的每个滑车最终都会使用最后写入的那个值。

其他固件风格只会得到一条不带工具头编号的压力提前命令。自适应压力提前只调整打印切片工具路径的那个工具头，即 T0 或其 Span 搭档（在 RepRapFirmware 上始终为驱动 0）；其他滑车保持初始值。在主模式下，温度和压力提前的行为与其他打印机相同。

### 预览

预览会让每个激活的滑车与 T0 一起播放动画，并在每个工具头周围画一个方框（大小取自喷嘴避让距离），方便你检查它们是否保持了间距。只有两个喷嘴避让距离都大于零时才会绘制方框。有 Span 搭档时，T0 所在龙门只在两者中正在打印的那一个上显示一个方框；另一个龙门的两个滑车角色相同时只显示一个方框；启用[固件管理区域]({{L22}})后则不绘制方框。如果方框挡住了工具路径，可以通过 **视图 → 显示 IDEX/IQEX 工具头** 关闭它们。

{{I4}}

只会绘制切片得到的工具路径：T0 的，以及其 Span 搭档的。其他滑车的路径不会绘制。

### 切片前检查

有些问题会导致该盘无法切片，并显示说明问题的提示：

- 零件或擦拭塔位于主区域之外，或位于避让条带之内。
- 在无法打印多种耗材的模式下，盘上使用了不止一种耗材。见[多色打印]({{L23}})。
- 在并行模式下使用了混合耗材。
- 盘上的耗材没有一种装在 T0 上，而 T0 是打印切片零件的工具头。

当另一个激活滑车的耗材类型与 T0 不同，或其热床温度与 T0 相差超过 5 °C 时，**切片单盘** 和 **切片所有盘** 也会显示一个警告，你可以接受或取消。热床温度由 T0 控制，所以其他滑车只能按 T0 设定的温度打印。这个警告可以在其对话框中关闭，并可通过[切片前警告]({{L24}})重新开启。

## 限制

- **不会逐层检查工具路径是否碰撞。** 放置检查能让零件避开避让条带，但不会检查每一层的运动。请在区域边缘留出余量。
- **不会检查 Brim 和裙边是否超出区域或进入避让条带。** 请在零件与区域边缘之间为它们留出空间。
- **每个挤出机各自的可打印区域不会与这些区域合并计算。** 零件只会与主区域进行比对检查。
- **删除某个模式** 会把正在使用它的已打开的盘切换为主模式。如果盘指定的模式在打印机中已不存在（例如被重命名过，或在已保存的项目中），则切片时会给出警告并按主模式打印。
- **所有滑车都打印同一个零件。** 在同一模式下，各滑车不能打印不同的对象。
