# 校准指南

本指南系统、全面地介绍了 OrcaSlicer 的校准流程。

内容涵盖流量比例、压力提前、温度塔、回抽测试以及进阶校准技巧等关键环节。每个部分都配有分步说明和图示，帮助你更好地理解并有效完成每一项校准。

校准功能位于 OrcaSlicer 界面的 **校准** 菜单中。

校准分为两组。请按所列顺序进行，因为每项测试都建立在前面测试结果的基础上。

> [!NOTE]
> 这些测试默认挤出机本身已在打印机固件中校准好（E-steps 或 rotation distance）。大多数现代打印机出厂时就已设置正确。不同耗材之间的细微差异会在之后的[流量比例]({{L1}})步骤中修正。

## 耗材校准

每换一种新耗材，都要重复这些测试。

1. **[温度]({{L2}})：** 首先校准喷嘴温度。这一步至关重要：温度会影响耗材的黏度，进而影响它在喷嘴中的流动以及与打印床的附着，后续所有测试都依赖于它。这项测试快速、结果易读，适用于任何打印机上的任何材料。对于适用温度范围较窄的材料尤其重要。  
   {{I2}}
2. **[最大体积流量]({{L3}})：** 确定温度后，测出热端在这种耗材下能达到的最大体积流量。它给出一个安全上限，确保后续测试不会挤出不足或堵塞喷嘴。有些厂商会夸大这个数值，所以不要依赖料盘上标注的值。实际使用时取比测试结果低 10–20% 的值作为安全余量。  
   {{I3}}
3. **[压力提前]({{L4}})：** 校准压力提前（Pressure Advance）设置，以提升打印质量，减少喷嘴内压力波动造成的瑕疵。之所以放在流量比例之前，是因为它最常出错（或者根本没校准过），而大多数耗材配置中的流量比例本来就已经接近正确值。调好压力提前后，线条末端和转角也会更干净，流量比例测试的结果更容易判读。  
   {{I4}}
4. **[流量比例]({{L5}})：** 校准流量比例，确保挤出的耗材量正确。这对获得准确的尺寸和良好的层间结合很重要。测试以所选耗材配置中的流量比例为起点，因此通常只是小幅修正。  
   {{I5}}
5. **[回抽]({{L6}})：** 校准回抽设置，以减少拉丝、提升打印质量。默认值通常就够用；如果要校准，请在压力提前和流量比例之后进行，因为两者都会改变喷嘴内的压力。回抽不依赖下面的进阶测试，因此归在耗材校准中。  
   {{I6}}

> [!TIP]
> 压力提前和流量比例会相互产生轻微影响，所以先校准哪一个都可以。如果流量比例在校准步骤中变化很大，就再快速做一次压力提前测试。

## 进阶校准

这些测试是可选的。它们大多调整的是打印机而不是耗材，所以只需在硬件改动后重做。请在完成耗材校准后再进行，因为耗材没调好会影响这些测试的结果。

1. **[转角]({{L7}})：** 校准抖动（Jerk）/结点偏差（Junction Deviation）设置，以提升打印质量，减少尖角和方向突变造成的瑕疵。它主要用于提高过弯速度。大多数打印机并不需要，因为固件本身已经限制了转角速度：超过这个限制（尤其是在 Klipper 中）后，更大的数值并不会让实际打印更快，而且 OrcaSlicer 无法检测这一点。  
   {{I7}}
2. **[输入整形]({{L8}})：** 通过补偿打印机的机械振动来减少振纹、提升打印质量。大多数较新的打印机都有自带的自动输入整形校准，通常比这项手动测试更准确，有条件时应优先使用。  
   {{I8}}
3. **[VFA]({{L9}})：** VFA 速度测试可用来找出共振速度。请在输入整形之后进行，用来找出输入整形没有消除的垂直细纹（Vertical Fine Artifacts）。  
   {{I9}}
4. **[自适应压力提前]({{L10}})：** 根据不同的流量和加速度调整压力提前值。它需要先校准好压力提前和流量比例，而且其测试[不应超过输入整形测得的加速度上限]({{L11}})。  
   {{I10}}

---

**[公差]({{L12}})：** 校准打印机的公差，确保它能准确还原模型的尺寸。这对零件之间的良好配合以及最终打印件符合预期规格都很重要。请放在最后进行，因为结果依赖于上面的每一项校准。
