# 纹理置换 UV 编辑器

[纹理置换]({{L1}})的其他所有映射都是在猜测如何把图像包裹到表面上——从三个轴向、围绕一个中心，或者从相机视角。**展开 (LSCM)** 不靠猜测：它把绘制区域展平成一块块平放的小片，再把纹理映射到这些小片上。正因如此，它是唯一不会出现意外拉伸的映射，也是唯一需要你来做决定的映射。

UV 编辑器就是做这些决定的地方。把某个图层的映射选为**展开 (LSCM)**，这个窗格就会在 3D 视图旁打开。

{{I2}}

不把表面剪开就无法把它展平——立方体必须先剪成展开图才能平放。剪开的地方叫**切缝**，展平后的小片叫**UV 岛**（简称岛），整个工作就是决定在哪里剪开，以及如何摆放剪出来的各块。

{{T1}}

{{I1}}

窗格本身：顶部是图层及其平铺尺寸，下面是切缝和布局设置，左侧是工具，展平后的 UV 岛叠在图层自身的纹理上显示。

## 工作流程

1. 像使用其他映射一样，在模型上绘制区域。
2. 把图层的映射设为**展开 (LSCM)**，窗格随即打开。
3. 按**展开**。绘制区域会在其锐利的边处被剪开并展平。
4. 在**棋盘格**或**畸变**中查看结果。如果某一块拉伸严重，就在其中[标记一条切缝]({{L2}})，然后重新展开。
5. 如果想让图案落在特定位置，就摆放各个 UV 岛，然后在主面板中烘焙。

在有图层使用"展开"映射之前，窗格会显示*没有使用"展开"映射的图层*；在绘制任何内容之前，它会提示你先绘制区域。

## 展开

**展开**计算布局。有两项设置决定展开的结果，两者都在*下一次*展开时生效：

| 设置 | 作用 |
| --- | --- |
| **切缝角度** | 比这个角度更锐利的边会被剪开，两侧的部分分别展平。调低它会剪开更多的边：每一块展平时拉伸更小，代价是图案不能连续跨过切口。一旦你手动标记了任何切缝，就由你的切缝来划分各块，这项设置将被忽略 |
| **连接 UV 岛** | 把结果排布成相连的展开图——共享一条边的各块会相邻展开，所以立方体会变成一张相连的展开图，而不是六个分散的正方形。它们仍然是各自独立的 UV 岛，仍然可以手动移动。关闭它则使用普通的紧凑排布 |

底部的摘要会报告生成了多少个 UV 岛和多少个面。如果之后绘制、切缝或切缝角度有所改变，窗格会把布局标记为**已过期**——再按一次**展开**即可。

> [!NOTE]
> 重新展开会重新剪切并重新摆放每个 UV 岛，所以之前手动做的摆放都会被丢弃。先把切缝定好，再进行摆放。

## 切缝

切缝是强制展开沿之剪开的边，在切缝角度自动剪开的边之外额外生效。你可以用它们精确决定图案允许在哪里断开——把它们放在断开处不显眼的地方：内角、零件的背面，或者本来就是一条特征线的地方。

| 控件 | 作用 |
| --- | --- |
| **标记切缝** | 单击模型上的边，沿这些边剪开。光标下的边以黄色高亮；单击将其标为红色，再次单击红色的边则取消标记。开启期间暂停绘制 |
| **路径** | 不必逐条单击边，只需单击一个起点再单击一个终点——两点间的整条最短路径会一次性标为切缝，之后每次单击都从上一个点继续。在高密度网格上必不可少 |
| **清除切缝** | 移除此图层上的所有切缝 |

标记时按住 **Ctrl** 拖动可以移动相机。

## 摆放 UV 岛

三种模式决定拖动时移动的对象：

| 模式 | 编辑对象 |
| --- | --- |
| **岛** | 整个 UV 岛——移动、旋转、缩放 |
| **顶点** | 单个顶点，用于调整 UV 岛的形状 |
| **边** | UV 岛的边，用于调整 UV 岛的形状 |

按住 **Shift** 或 **Ctrl** 单击可以加选或减选，之后拖动会让所有选中的对象一起移动。拖动时模型会同步更新，你可以看到图案落在哪里。

**清除 UV 编辑**会放弃手动的顶点和边移动，使展开恢复为自动生成的形状。

## 检查拉伸

展开是把曲面展平，而展平总会造成某种变形。有两种背景可以让变形可见——它们同时也会给 3D 视图中的模型着色，让你在两个地方同时判断。

| 背景 | 解读方式 |
| --- | --- |
| **高度图** | 在 UV 岛下方显示图层自身的纹理，平铺方式与烘焙时完全一致。也就是你实际会得到的效果 |
| **棋盘格** | 一张测试网格。保持正方形的方格没有变形；被拉成长方形的方格表示图案在那里会被拉长 |
| **畸变** | 按每个 UV 岛相对于其他部分的拉伸程度，从蓝到红着色 |

如果某个 UV 岛拉伸严重，说明它被要求平放而实际上做不到。在其中标记一条切缝并重新展开——剪开得越多，拉伸越小。

## 工具

| 工具 | 作用 |
| --- | --- |
| **平均缩放** | 使每个 UV 岛具有相同的纹素密度，这样手动缩放过的岛可以重新与相邻的岛匹配 |
| **切开** | 沿所选 UV 岛的长轴将其拆分——用于无法整块平放的狭长弯曲 UV 岛 |
| **拼接** | 沿共享边把所选 UV 岛展开到其最近的相邻岛上。两者仍然是各自独立的 UV 岛 |
| **取消拼接** | 把所选 UV 岛送回其自身的排布位置 |
| **吸附** | 把一个 UV 岛拖向另一个时，让它们贴合在一起 |
| **适配视图** | 让所有 UV 岛在窗格中完整显示 |

## 导航与快捷键

| 输入 | 操作 |
| --- | --- |
| 左键单击 | 选择 |
| Shift 或 Ctrl + 左键单击 | 加选或减选 |
| 左键拖动 | 移动所选对象 |
| 右键拖动 | 旋转所选 UV 岛 |
| **R** | 用鼠标旋转；单击或按 **Enter** 确认，按 **Esc** 取消 |
| **S** | 用鼠标缩放；单击或按 **Enter** 确认，按 **Esc** 取消 |
| 旋转时按住 **Shift** | 以 15 度为步长吸附 |
| 中键拖动 | 平移 |
| 鼠标滚轮 | 以光标为中心缩放 |
| **Home** 或 **F** | 让所有 UV 岛完整显示 |
| **Ctrl+Z** / **Ctrl+Y** | 撤销 / 重做布局更改 |

底部的状态栏始终会显示当前正在进行的操作及其可用的按键。
