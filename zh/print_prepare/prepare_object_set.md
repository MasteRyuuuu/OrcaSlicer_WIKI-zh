# 对象集

对象集是 OrcaSlicer 中用来组织和管理 3D 模型的基本结构。它让用户可以把多个物体及其各自的零件归为一组，便于操作、配置和切片。

## 零件

每个对象集由一个或多个零件组成。  
零件代表导入到项目中的单个 3D 模型或网格。每个零件都可以有自己独立的设置，例如打印参数、支撑和修改器。

## 实例

实例是放在打印床上的对象集的一个具体副本。  
同一个对象集的所有实例共用相同的零件、尺寸和设置，但每个实例在打印床上可以有自己的位置和旋转角度。  
当你想打印同一个模型的多个副本、同时保持相同的绘制设置（[颜色]({{L1}})、[绒毛表面]({{L2}})、[接缝]({{L3}})、[支撑]({{L4}})等）时，这会很有用。

## 拆分

### 拆分为对象

选中包含多个零件的对象集时，可以选择把它拆分为单独的对象。  
每个对象包含原对象集中的一个零件。

### 拆分为零件

选中只有一个零件、但该零件包含多个网格的对象时，可以选择把它拆分为单独的零件。  
每个零件代表原对象中的一个网格，可以独立操作和设置。
