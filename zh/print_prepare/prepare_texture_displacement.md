# 纹理置换

纹理置换把纹理绘制到模型上，并把它变成**真实的起伏**——握得住的滚花、摸得到的砖纹、刻进盖子的标志。

关键在于它不是打印时的效果。[绒毛表面]({{L1}})在切片时扰动刀路，模型本身保持不变；纹理置换则会重写网格。一旦烘焙，起伏就是普通的几何体：它的切片、预览、导出和测量都与其他任何形状一样，切片软件完全不知道这里曾经用过纹理。

{{I4}}

一块 50 mm 的平板，烘焙了内置的 **Hexagons**（六边形）高度图：输入 12 个三角面，输出 206 k 个，从此它就只是一个网格。

{{I5}}

决定最终效果的有三件事，面板上的每个控件都属于其中之一：

| | 决定什么 | 控件 |
| --- | --- | --- |
| **哪里** | 表面的哪一部分受影响 | 绘制工具。绘制区域以外的部分都不会被改动 |
| **什么** | 起伏的形状 | 纹理图像、深度、平铺尺寸、中间值以及其余图层设置 |
| **多精细** | 网格实际能容纳多少形状细节 | 分辨率和预算 |

前两项设对、第三项设错，是最常见的失望来源：精心设置的纹理烘焙到过于粗糙的网格上，出来只是一些柔和的鼓包。[烘焙]({{L2}})一节讲解如何避免。

{{T1}}

另有两页介绍拥有独立面板的部分：**展开**映射所用的 [UV 编辑器]({{L3}})，以及开放网格预处理步骤的[专业模式]({{L4}})。

> [!TIP]
> 如果只想在模型上放一张彩色图片、完全不要起伏——标志、照片、标签——[图像]({{L5}})工具就是去掉了深度、面板也短得多的本工具。

## 快速上手

1. 选中一个对象，从 3D 视图上方的工具栏打开**纹理置换**。系统会自动为你添加一个图层。
2. 单击图层的图像，选择一个纹理——**Knurl**（滚花）很适合入门。
3. 绘制要应用纹理的区域，或者按**选择整个模型**。
4. 起伏会随着你的操作显示出来。把**深度**设为它应凸起的高度，把**平铺尺寸**设为图案一份副本的大小。两者都以毫米为单位，指的是模型上的尺寸。
5. 按**烘焙**。

整个流程就是这样，其余都是细化。

> [!TIP]
> 烘焙之前一切都不是永久性的，而且一次烘焙只是一个撤销步骤。尽管放手尝试。

## 面板

{{I1}}

1. **标准 / 专业**——专业模式增加网格预处理控件。
2. **绘制工具**——如何标记区域。鼠标右键执行与当前模式相反的操作。
3. **视图**——调参时用"快速"，要查看烘焙结果时用"普通"。
4. **图层**——它的图像、绘制区域和设置。最多 8 个图层，像图像编辑软件中的图层一样堆叠。
5. **分辨率和预算**——网格细化到多细，以及为此最多可以花费多少三角面。
6. **烘焙**——把预览变成真实的几何体。**关闭**则不烘焙直接离开。

面板顶部的**停靠面板 / 取消停靠面板**可以把它固定在 3D 视图侧边，或让它自由浮动在视图上方。无论选哪种，离开工具时你的绘制区域、图层和设置都会随模型保留。

> [!TIP]
> 面板中的每个滑块也都可以输入精确数值：**Ctrl+单击**滑轨，或按其右端的小编辑图标。鼠标悬停在滑块上会显示它的作用和可接受的范围。

## 标准与专业

| 模式 | 显示内容 | 适用情况 |
| --- | --- | --- |
| **标准** | 绘制、图层、映射、烘焙 | 几乎所有情况 |
| **专业** | 同上，另外把细分、重新网格化和结果平滑作为单独的步骤 | 你想先准备一次网格，再在上面试几种纹理；或者自动选择的三角面数量过多 |

高度图只能移动已经存在的顶点，所以模型必须先有足够多的顶点，才能显示出细节。标准模式在烘焙时按底部的分辨率完成这一步。专业模式把同样的机制拆成单独的按钮交给你——参见[专业模式]({{L6}})。

## 绘制区域

绘制标记的是图层应用的*位置*。每个图层都有自己的绘制区域，你绘制的内容会进入**活动图层**——即列表中高亮的那一个。

| 控件 | 作用 |
| --- | --- |
| **绘制** | 在你单击或拖动的位置添加到活动图层。鼠标右键擦除 |
| **擦除** | 移除绘制。鼠标右键绘制 |
| **画刷** | 手绘。**画刷尺寸**设置半径；**圆**绘制从相机看过去画刷覆盖的所有内容，**球体**只绘制光标周围一个球体范围内的部分，在弯曲或折叠的表面上应使用后者 |
| **面** | 逐个单击三角面。在低面数模型上很精确，在高密度模型上则很繁琐 |
| **连通区域** | 从单击处开始填充。**角度阈值**让填充在比给定角度更锐利的边处停止，因此单击一次可以选中盒子的一整个面，而不会选中整个盒子 |
| **选择整个模型** | 用活动图层绘制所有面 |
| **擦除整个模型** | 清除活动图层在各处的绘制 |

按住 **Ctrl** 拖动可以移动相机而不绘制。

> [!TIP]
> 绘制边界是起伏与裸露表面的交界，默认会在这里陡降到表面。图层上的**边缘渐隐**可以把它柔化成坡面——参见[塑造起伏]({{L7}})。

## 预览效果

**视图**一行决定 3D 视图显示什么。前四项互斥，**线框**是独立的开关。

| 视图 | 显示 | 说明 |
| --- | --- | --- |
| **普通** | 真实的置换几何体——与烘焙结果完全一致 | 在后台重建，所以区域较大时会有延迟 |
| **快速** | **仅活动图层**的着色近似效果，几何体不移动 | 开销小，适合工作时使用 |
| **棋盘格** | 覆盖在展开结果上的测试网格。展开没有拉伸的地方，方格保持方正 | 仅限**展开**映射 |
| **畸变** | 从蓝到红的热图，表示展开的拉伸程度 | 仅限**展开**映射 |
| **线框** | 网格的边，叠加在当前视图上 | 是开关，不是互斥选项 |

拖动滑块时在**快速**视图中工作，确定之前切换到**普通**。两者可能不同：快速视图只显示一个图层，忽略图层之间的混合，着色也是近似的。

**自动**（默认开启）会在任何内容变化时重建普通视图。在较重的模型上把它关掉，就只会在你松开滑块或完成一笔绘制时才重建。

## 纹理

纹理是一张被当作高度读取的灰度图像——白色把表面抬高**深度**的量，黑色保持不变。

单击图层的图像打开选择器。它大小固定、可以滚动，其中每个分组都是可折叠的区块，单击即可收起。**内置**附带 43 张无缝高度图，全部都能平铺而看不出接缝：

{{I6}}

**纹理库**中是[插件]({{L8}})提供的纹理包。每个包都是一个以包名命名的可折叠区块，不用的包可以收起。启用或卸载一个包会增加或移除对应的区块。**探索更多纹理库**会打开 OrcaCloud 浏览纹理包。

最后的**我的纹理**存放你自己的纹理。导入 PNG、JPG 或 BMP 后，它会被转换为高度图并复制到你自己的纹理文件夹中，应用程序更新不会覆盖它。鼠标悬停在你自己的纹理上即可删除它。

适合作为高度图的图像应当：

- **无缝**——如果你要平铺它。光照不均的照片会显出一格一格的接缝。
- **色阶完整。** 发灰的图像只用到可用深度的一小部分；先拉开它的对比度。
- **光照平均。** 照片里的阴影会被读成深度，所以一张有侧光的砖墙照片会把它自己的阴影也刻出来。
- **不过分精细。** 比网格分辨率更小的细节打印不出来，只会白白消耗三角面。参见[烘焙]({{L9}})。

> [!TIP]
> 更换图层的图像会保留它的绘制区域、深度和平铺设置，所以你可以逐个试用纹理，而无需重新设置。

### 调整图像

图层使用的图像很少一拿来就完美：照片太软，扫描图太平，渲染图带有噪点。图层名称旁的图标会打开该图层图像的调整面板。

| 滑块 | 作用 |
| --- | --- |
| **亮度** | 把整张图像整体提向白色，或压向黑色 |
| **对比度** | 以中灰为中心拉开明暗。照片出来只是一片浅而模糊的起伏时，首先就调它 |
| **锐度** | 突出最精细的细节；它在模糊之后应用，所以两者可以同时使用 |
| **模糊** | 柔化图像本身。与图层的**平滑**不同，平滑是柔化起伏而不改变图像——先试试平滑 |
| **色相** | 转动彩色图像的颜色。灰度图像没有色相可转，此项不可用 |

{{I2}}

面板打开时的样子，所在图层的图像是一个色轮。

{{I3}}

同一个图层把**色相**转动 120 度后：每种颜色都沿色轮走了三分之一圈，拖动时预览实时跟随，一旦确实有了改动，**另存为副本**就会变为可用。

这个面板是普通窗口而不是模态对话框，所以后面的 3D 视图依然可以操作：一边拖动，一边旋转模型观察起伏的变化。移动滑块时图像预览实时更新，松开后模型跟着更新。

由于调整后的像素*就是*图层使用的图像，它们同时驱动颜色和起伏——调高亮度确实会让起伏变高。这是有意为之：一张图像、一个唯一的依据，而不是另一套需要烘焙按正确顺序重放的旋钮。

**另存为副本**会把调整后的图像作为新文件写入你自己的纹理库，并让图层指向它。这是让调整永久生效的唯一方式——**取消**或关闭面板都会让图层恢复原样。未保存的调整也不会写入项目，所以在调整中途保存的 `.3mf` 中存放的是原始图像。

## 图层堆叠

最多可以堆叠 **8** 个图层，每个都有自己的绘制区域、图像和设置。它们按列表顺序组合，就像图像编辑软件中的图层：**上移**更早应用，**下移**更晚应用。

两个图层重叠的地方，由上面那个图层的**混合**模式决定结果：

| 混合 | 效果 | 典型用途 |
| --- | --- | --- |
| **相加** | 把本图层的起伏叠加在下方之上 | 在基础图案上添加划痕或噪点 |
| **相减** | 从下方挖去本图层的起伏 | 在滚花区域中压印一个光滑的标志 |
| **相乘** | 用本图层缩放下方的起伏 | 遮罩——在本图层较暗的地方让图案淡出 |
| **相除** | 在本图层较暗的地方放大下方的起伏 | 很少用；上限为 20×，因此不会失控 |
| **覆盖** | 用本图层的值替换下方，而不是与之组合 | 在图案中压出一块平面，你只要本图层的高度、不要它所覆盖的任何内容 |

{{I7}}

最下面的已绘制图层是**基础图层**：它下方什么都没有，所以总是相加，面板会直接说明这一点，而不是提供一个不起作用的控件。

没有绘制的图层会标记为**未绘制**，烘焙时会被跳过——烘焙按钮下方的提示会列出它们。

## 塑造起伏

几乎每个图层都需要的三个控件就在图层上；**更多设置**打开其余的控件。

| 控件 | 作用 |
| --- | --- |
| **深度** | 白色把表面抬高多少，单位为毫米 |
| **平铺尺寸** | 纹理的一份副本在模型上有多宽。越小重复越频繁、细节越细。**平铺**关闭时，这是那唯一一份副本的大小 |
| **旋转** | 在表面上转动纹理，用于让图案与某条边对齐 |
| **平滑** | 在使用之前模糊图像。可以磨圆生硬的台阶、去除噪点照片中的斑点，代价是损失精细细节 |
| **边缘渐隐** | 让起伏朝绘制区域的边缘逐渐变平，与裸露表面融为一体。滑块设置渐隐向内延伸多远 |
| **反转** | 把起伏内外翻转——与使用图像的负片相同 |
| **平铺** | 纹理是否重复。**重复**直接平铺，**镜像重复**每隔一块翻转一次，使边缘无缝衔接。关闭则只放一份，像贴花一样 |

**中间值**决定哪种灰色表示"保持原位"，正是它让同一张图像既能用来做浮雕，又能用来做雕刻：

{{I8}}

为 **0**（默认）时，起伏只会升高：黑色停在原表面上，白色凸起"深度"的高度。为 **0.5** 时，中灰保持原位，较浅的灰色升高，较深的灰色向内切入。

> [!WARNING]
> 向内切入的部分必须容得下。在尖锐的内凹角内，或在薄壁上，较深的向内切割可能穿透零件的另一侧。当深度较大且中间值大于 0 时，面板会发出警告；在这些地方应让深度远小于壁厚。

## 映射

映射决定平面图像如何包裹到你绘制的弯曲、折叠的表面上。图案能否干净利落地跨过边缘，就由这个设置决定。

{{I9}}

| 映射 | 适用于 | 须知 |
| --- | --- | --- |
| **三平面（混合）** | 默认；任何需要绕过边缘的情况 | 从三个轴向投影并在它们之间混合，所以转角处没有硬接缝——但图案会在紧贴边缘的一条带内交叉淡化 |
| **圆柱** | 握把、旋钮等管状物体 | 围绕绘制区域自身的中心包裹 |
| **球面** | 圆顶和球体 | 在两个方向上围绕中心包裹 |
| **展开 (LSCM)** | 必须连续而均匀延续的图案 | 真正的展开，在锐利的边处切开，在 [UV 编辑器]({{L10}})中排布，你可以手动整理。唯一不会出现意外拉伸的映射——也是唯一需要花功夫的映射 |
| **从视图** | 贴花和一次性放置 | 从你当前的视角投影到绘制区域上。背向你倾斜的表面会被拉糊 |
| **模型 UV** | 已带有纹理坐标的模型 | 使用模型创作时的 UV 布局，所以为该模型制作的纹理会准确落在作者预期的位置。仅当模型带有 UV 时才提供，并且默认选中。**平铺尺寸**在这里不起作用——布局*就是*放置方式，一份纹理正好覆盖它 |

**从视图**有自己的控件：**捕获当前视图**按相机重新获取方向；**仅投影到可见面**用相机能看到的面重新绘制该图层（它会替换图层的绘制区域，而不是追加）；**投影框**会打开一个半透明窗口，你可以像幻灯机的片门一样把它拖到 3D 视图上——**应用投影框**让它的边框成为投影的硬边界，**清除**则恢复为普通投影。

**调整位置**用模型上的一个手柄代替绘制：拖动平面板可自由移动纹理，拖动箭头则沿一个轴移动。先绘制一些区域——手柄锚定在绘制区域上。

{{I10}}

一个带有自身 UV 布局的模型上的图层：**模型 UV** 是第六种映射并已为你选中，**平铺尺寸**呈灰色，因为布局已经决定了放置方式。

{{I11}}

一张刻意不对称的测试图像——一个箭头、四个各不相同的角标、底部一条虚线带——放在一块平板上。箭头指向模型上方，虚线带留在底部，由此一眼就能看出纹理既没有上下颠倒，也没有镜像。

> [!NOTE]
> 在任何映射下，纹理都是正向放置的，并且从模型的一侧到另一侧都不会镜像。早期版本在三平面映射下会把纹理上下颠倒，并在立方体六个面中的三个面上镜像。如果你重新打开在此修正之前制作的项目，**重新烘焙时纹理的放置方式会与第一次烘焙不同**——已经烘焙进网格的起伏属于几何体，不受影响。

## 颜色

彩色图像除了驱动起伏，还可以驱动打印的颜色。只有当图层的图像是彩色时，**颜色**复选框才可用——灰度高度图没有可应用的颜色。

开启后，纹理中的每种颜色都会匹配到盘上已装载耗材丝中最接近的那一种。没有绘制的部分保持对象本身的耗材丝。烘焙时，结果会写入对象的[涂色]({{L11}})数据，所以它的切片、预览和打印都与手工涂色完全相同，之后也可以用涂色工具修饰。

| 控件 | 作用 |
| --- | --- |
| **混合耗材丝** | 交错使用两种耗材丝来模拟它们之间的颜色，这样少数几种耗材丝也能表现照片或渐变。由纯色块组成的图像无论是否开启，打印结果都一样 |
| **混合方式**（Mix by） | **层**在打印层之间交替两种耗材丝——在竖直壁面上很平滑，在朝上的平面上则看不出效果，因为那里一整层就是一条色带。**表面**使用细密的棋盘格，任何角度都有效，但可能看起来像纹理。**自动**在竖直面上按层交替，在朝上的平面上使用更接近的单一耗材丝 |
| **去噪** | 清除颜色错误的零星三角面。结果看起来有斑点时调高；小特征被吞掉时调低 |

控件下方的一行会报告当前耗材丝能产生多少种可打印的颜色。

模型上已有的颜色会被保留。这涵盖了问题的两个方面：模型**导入时自带**的颜色——带材质的 `.obj`，或彩色的 `.3mf`——即使烘焙重建了下面的网格也能保留；**先前烘焙**的颜色在下一次烘焙后也会保留，所以连续多次烘焙会累积，而不会相互覆盖。本次烘焙的颜色叠加在原有颜色之上；它没有着色的三角面保持原样。

> [!NOTE]
> 颜色边缘的清晰度取决于沿边缘的三角面，因为每个三角面只用一种耗材丝打印。专业模式的**颜色细节**会在颜色交界处细化网格——没有其他步骤会在那里细化，因为颜色变化处的表面是平的。

## 烘焙

烘焙把预览变成几何体。底部的两个控件决定纹理在这个过程中能保留多少。

**分辨率**是烘焙时把绘制区域细化到的三角面尺寸。它必须小于你想从纹理中得到的细节：

{{I12}}

保持勾选**自动**，分辨率会随模型尺寸变化，这适合大多数零件。当纹理比它所在的零件精细得多或粗糙得多时，取消勾选。

**预算**是烘焙可以在绘制区域上花费的三角面数量（以千计）。模型上其他地方已经烘焙的起伏在此之外另行保留，所以在别处进行第二次烘焙时，会获得与第一次相同的预算。

预算是上限，分辨率是需求，所以当需求远超上限时，面板会在烘焙*之前*发出警告。烘焙仍会执行，但会简化回预算以内，细节也随之丢失。请提高预算，或把分辨率设得粗一些。

> [!IMPORTANT]
> 分辨率是以毫米为单位的三角面尺寸，所以数值**越小**网格越细——减半大约需要**四倍**的三角面。之后每个三角面都会在项目的整个生命周期里消耗切片时间、内存和文件大小。把它设得比你真正想摸到的最小特征稍细一点即可，不必细到图像的极限。

**烘焙**在后台运行，按钮显示*正在烘焙...*；**停止**可提前结束，并保留已完成的部分。完成后：

- 起伏成为网格的一部分，整个烘焙是一个撤销步骤。
- 每个已烘焙图层的绘制区域会被清除——这些三角面描述的已不再是原来那个未烘焙的表面。图层、纹理和设置会保留，你可以继续在别处使用它们。
- 颜色写入对象的[涂色]({{L12}})数据。

## 保存项目

面板中的所有内容都会写入 `.3mf`，所以重新打开项目时，起伏依然处于设置好、可编辑的状态——而不只是烘焙后的几何体。

随项目保存的内容：

- 图层堆叠，以及每个图层上的所有设置。
- 每个图层的**纹理图像**，直接复制进项目压缩包。在另一台机器上打开项目，或者整理了纹理文件夹之后，项目依然带着它的纹理。
- 每个图层的**绘制区域**。
- **展开相关的工作**：你标记的切缝、手动摆放的 UV 岛，以及单独的 UV 编辑——参见 [UV 编辑器]({{L13}})。
- 选中了哪个图层，以及你处于标准模式还是专业模式。

不会保存的内容：

- 预览网格，重新打开项目时会重建。
- 面板是否停靠，这属于应用程序偏好设置，而不是模型的属性。

项目文件双向兼容：旧版 OrcaSlicer 打开这些文件时会直接忽略纹理数据，而本版本打开旧项目时只是找不到需要恢复的内容。烘焙后的起伏和颜色都是普通的模型几何体，所以一直都会被保存，现在也是。

## 示例

三个可以直接照做的完整示例，全部假设使用标准模式。

### 圆形把手上的滚花握把

1. 绘制要握持的环带——用**连通区域**配合较低的角度阈值，通常单击一次就能选中。
2. 纹理选 **Knurl**（滚花），映射选**圆柱**。
3. **平铺尺寸** 4 mm，**深度** 0.35 mm，**中间值** 0。
4. 取消勾选**自动**，把分辨率设为约 **0.12 mm**——滚花的棱只有零点几毫米宽，三角面必须比它更小。
5. 烘焙。

### 平面上的雕刻标志

1. 把标志作为纹理导入——一开始用黑底白色图形即可。
2. 绘制该面，映射选**从视图**，并正对着它看。按**捕获当前视图**。
3. 关闭**平铺**以只得到一份，并用**平铺尺寸**调整大小。
4. **深度** 0.4 mm。现在标志是凸起的；如果要把它压入面内，把**中间值**设为 0.5 并勾选**反转**。
5. 用**调整位置**把它滑到合适位置，然后烘焙。

### 整个模型的木纹

1. **选择整个模型**，纹理选 **Wood Grain**（木纹），映射选**三平面**。
2. **平铺尺寸** 40 mm——木纹的尺度要比它所含的细节大得多。
3. **深度** 0.25 mm，**平滑** 0.2，去掉生硬感。
4. 分辨率保持**自动**，烘焙前检查三角面警告；整个模型的烘焙是开销最大的情况。

## 故障排除

| 现象 | 可能原因 | 解决办法 |
| --- | --- | --- |
| 按烘焙时提示*尚未绘制任何区域* | 没有绘制，或者 UV 编辑器的切缝工具处于开启状态，笔画在标记切缝 | 绘制区域，或在 UV 窗格中关闭**标记切缝** |
| 某个图层没有效果 | 它没有绘制——烘焙按钮下方的提示会列出被跳过的图层 | 把它设为活动图层并绘制 |
| 起伏出来柔软圆钝 | 分辨率对图案来说太粗，或者预算迫使网格简化 | 设置更细的分辨率（更小的毫米值）、提高预算，并留意烘焙按钮上方的警告 |
| 起伏看起来生硬或有斑点 | 图像有噪点，或有生硬的台阶 | 调高图层的**平滑**，或在专业模式中使用**平滑结果** |
| 图案在锐利边缘的一条带内交叉淡化 | **三平面**映射的固有特性 | 使用**展开**并沿该边标记切缝 |
| 图案在区域的部分位置被拉糊 | 在背向相机倾斜的面上使用了**从视图** | 换个更好的角度重新捕获，或改用其他映射 |
| 起伏穿透了壁 | 薄壁上使用了较高的**中间值**和较大的**深度** | 减小深度，或把中间值改回 0 |
| 三角面数量暴增 | 分辨率远比特征尺寸精细 | 调粗分辨率；减半意味着 4× 的代价 |
| 颜色看起来有斑点 | 细节比网格能承载的更精细 | 调高**去噪**，或在专业模式中降低**颜色细节** |
| 预览与烘焙结果不一致 | **快速**视图只显示活动图层，而且是近似效果 | 判断前切换到**普通**视图 |
| 使用其他工具后绘制消失了 | 简化、重新网格化或细分替换了几何体 | 重新绘制，并在绘制*之前*完成网格处理 |

## 限制

- **任何替换几何体的操作都会丢弃未烘焙的绘制**——简化，以及专业模式的细分和重新网格化。已经烘焙进去的起伏不受影响。
- **UV 岛的摆放与当前展开绑定。** 它们会随项目保存，但重新绘制或修改切缝角度会重新切分各块，并丢弃在此之前手动做的摆放。
- **快速视图只是近似效果**，并且只显示活动图层。
- **起伏不能超出网格所能容纳的程度。** 无论滑块怎么设置，都不存在比预算所能负担的分辨率更细的细节层级。
