# 图像

**图像**工具把一张彩色图片放到模型上：盖子上的标志、铭牌上的照片、瓶身上的标签。表面保持原有形状——既不凸起也不雕刻——图片靠在表面上切换耗材丝来打印出来。

{{I2}}

一个十二色相的色轮放在一块平板上。表面完全没有移动；你看到的是图片中每种颜色都被匹配到已装载的四种耗材丝中最接近的那一种，所以十二个色块最后只出来四种颜色和两种混色。

它就是关闭了起伏的[纹理置换]({{L1}})引擎。这里能做的一切，也都可以在那个工具里把深度设为零并勾选"颜色"来完成；这个工具舍弃了图层堆叠、混合模式和深度控制，换来单张图片和更短的操作路径。如果你还想要起伏，或者要在同一个模型上放多张图片，就改用纹理置换。

{{T1}}

## 快速上手

1. 选中一个对象，从 3D 视图上方的工具栏打开**图像**。
2. 单击图片方块并选择一张图片，或者直接从文件管理器把图片拖到 3D 视图上。
3. 在模型上单击图片要放的位置。单击一次就会占满整个面。
4. 设置**大小**；如果需要与某条边对齐，再设置**旋转**。
5. 按**应用**。

> [!NOTE]
> 图片用你装载的耗材丝打印，所以双色标志需要盘上有两种耗材丝，照片则是能给多少种就给多少种。单耗材丝打印机也可以放置图片，但图片中的所有内容都会用那一种耗材丝打印。

{{I1}}

面板从上到下依次是：图片及其位置，然后是**放置**（怎样贴上去、多大、多清晰）、**颜色**（在与耗材丝匹配之前对图片做的校正）和**背景**（哪些部分不打印）。**应用**把结果写入模型。

## 选择图片

单击面板顶部的方块打开选择器。它和纹理工具共用同一个图库：随软件附带的图片，以及**我的纹理**下你自己的图片。导入文件会把它复制到你自己的文件夹中，应用程序更新不会覆盖它。

图片必须是**彩色**的。灰度图像是高度图，没有可用第二种耗材丝打印的内容，面板会直接提示，而不会让你应用它。

带**透明度**的图片可以被正确识别：透明部分不打印，露出对象本身的颜色。导出为 PNG 的标志通常正需要这样，而且不需要任何设置。

你也可以把图像文件从桌面拖到 3D 视图上。文件悬停在画布上方时会出现一个虚线框；松开后图像会导入图库并加载，下次也还在。

## 放置图片

单击模型，图片就落在那里。从单击的点开始，图片沿表面向外扩散，遇到第一处比**扩散**（Spread）更尖锐的折角就停下——所以在平坦的侧面、立方体的面或面板上，单击一次就够了。在多面体模型上降低**扩散**可以把它限制在一个面上；提高它则能让它绕过平缓的曲面。单击别处即可移动它。

| 控件 | 作用 |
| --- | --- |
| **映射** | 平面图片如何贴到表面上。**平面**（Flat）直接投影上去，适合单个面或平坦的侧面；**环绕**（Around）把它绕着区域包裹，适合杯子或管子；**球面**（Ball）在两个方向上包裹，适合圆顶；**从视图**从你当前的视角投射上去，就像幻灯机一样 |
| **捕获当前视图** | 配合**从视图**使用，按相机重新获取投射方向。先把视图对准表面——背向你的面会被拉伸 |
| **大小** | 图片在模型上的宽度，单位为毫米 |
| **旋转** | 在表面上转动图片，用于与某条边对齐 |
| **在模型上移动**（Move on the model） | 用一个可拖动的手柄代替单击：拖动平面板可自由移动，拖动箭头则沿一个轴移动 |
| **平铺** | 在区域内重复图片，而不是只放一份。默认关闭，因为照片或标志通常只贴一次 |

## 校正颜色

这些滑块在图片与耗材丝匹配之前修改图片。把它们放在这里而不是交给图像编辑软件，原因就在于：你的耗材丝是一组固定而随意的颜色，往往只需小小的校正，就能让图片与它们对得上。

| 滑块 | 作用 |
| --- | --- |
| **亮度** | 整体调亮或调暗图片 |
| **对比度** | 拉开明暗差距。照片打印出来一片浑浊时调高；所有内容都挤到最亮和最暗的耗材丝上时调低 |
| **饱和度** | 颜色的浓烈程度。为 0 时图片变成灰色，会用你的灰色和黑色耗材丝打印；调高则会把每个区域推向更纯的耗材丝颜色 |
| **色相** | 让每种颜色绕色轮转动，而亮度不变。如果你装了橙色但没有红色，稍微转一点就能把红色部分落到橙色上 |
| **伽马**（Gamma） | 提亮或压暗中间调，最亮和最暗的部分保持不变 |
| **锐化**（Sharpen） | 让边缘更清晰。这在这里比在照片里更有价值：两种颜色之间柔和的边缘量化后会变成一条两色混杂的参差带，先锐化能让边界落在同一个位置 |
| **颜色**（Colours） | 在与耗材丝匹配之前，把图片减少到最多这么多种颜色。选出的是图片实际由之构成的颜色，而不是均匀划分色域，所以格子呢图案能保留它自己的绿色和红色。**关闭**则不做处理 |
| **负片**（Negative） | 反相打印图片，明暗互换，每种颜色变成其补色 |

{{I3}}

**颜色**关闭：图片保留原有的全部色阶，天空是平滑的渐变。

{{I4}}

同一张图片减少到四种颜色。渐变变成了平坦的色带，太阳也融进了天空——这本来就是用四种耗材丝打印时会发生的事，所以最好在这里先看到并加以判断。

**全部重置**（Reset all）会把所有校正和背景设置恢复到初始状态。图片的放置位置和大小不受影响。

> [!TIP]
> 应该是两种纯色的标志，把**颜色**设为 2；海报设为 4 或 5；照片则保持关闭。它限制的是图片使用的颜色数；如果选出的两种颜色匹配到同一种耗材丝，结果实际需要的耗材丝还可能更少。

## 去除背景

标志通常放在一张白色卡片上，而把这张卡片也打印出来，一般不是你想要的。**去除背景**（Remove background）会让这部分不打印，露出对象本身的颜色，而不是一大块白色。

{{I5}}

不启用时，画着色轮的那张卡片也会被打印——圆盘周围的白色方块是耗材丝，而不是露出来的打印板。

{{I6}}

启用后，只打印彩色的色块。注意色轮中间的孔也一起被去掉了：它是同样的白色，而抠除针对的是颜色，而不是区域。如果这不是你想要的，就降低**容差**，或者用吸管拾取背景色。

默认情况下，要去除的颜色取自图片的**四个角**，这几乎适用于所有标志。如果不适用：

- 单击色块，手动选择颜色。
- 或者按下吸管，在预览图或模型上单击背景。
- **四角**（Corners）恢复为从四个角取色。

**容差**表示与该颜色相差多少以内仍算作背景。如果还残留阴影或渐变，就调高；如果开始吃掉图片本身，就调低。

## 清晰程度

每个三角面只能用一种耗材丝打印，所以图片下面的网格必须比你想要呈现的细节更细。**细节**是应用时网格细分到的三角面尺寸，单位为毫米，它是决定两种颜色之间边缘能有多清晰的唯一参数。

越小，三角面数量增长越快：减半大约需要四倍的三角面，而每一个三角面在项目的整个生命周期里都要消耗切片时间、内存和文件大小。把它设得比你希望清晰可辨的最小特征稍细一点即可，不必细到图片的极限。

如果你要求的细节所需的三角面远超预算，面板会在应用前给出警告。应用仍会执行，但会简化回预算以内，图片会比滑块所示的更模糊。

## 应用

**应用**会细分图片下方的网格，并把颜色写入对象的[涂色]({{L2}})数据。之后它的切片、预览和打印都与手工涂色完全相同，之后也可以用涂色工具修饰。

- 整个应用过程是一个撤销步骤。
- **停止**可以提前结束耗时较长的应用；已完成的部分会保留在模型上，并且可以撤销。
- 模型上已有的颜色会保留，这张图片叠加在上面。在别处再应用第二张图片不会影响第一张。
- **关闭**退出工具。你的图片、放置位置和所有校正都保留在模型中，并随项目保存。

> [!WARNING]
> 表面不会移动，但图片下方的网格**会**被替换成更细的网格。正是这样才让颜色有了可以打印的地方。你之前在那里手工绘制的任何内容——支撑、接缝、绒毛表面、颜色——都会被带过去，但你精心简化过的模型将不再保持简化状态。

## 故障排除

| 现象 | 可能原因 | 解决办法 |
| --- | --- | --- |
| **应用**为灰色不可用 | 还没有放置图片，或者图像是灰度的 | 单击模型放置图片；选择一张彩色图片 |
| 图片打印出来颜色不对 | 你的耗材丝就是调色板，每种颜色得到的是与之最接近的那一种 | 装载更接近图片颜色的耗材丝，或者调整**色相**和**饱和度**，直到与现有耗材丝相符 |
| 打印出来一片浑浊 | 低对比度的照片分摊到太少的耗材丝上 | 调高**对比度**，并把**颜色**设为你实际拥有的耗材丝数量 |
| 边缘参差不齐 | 网格对于这种细节来说太粗 | 降低**细节**，并留意按钮上方的三角面警告 |
| 标志周围有白框 | 没有去除背景 | 勾选**去除背景**，如果还残留一圈边，就调高**容差** |
| 图片有一部分消失了 | **容差**高到连图片内部的颜色也被匹配 | 调低容差，或者改用吸管拾取背景色，而不是取自四角 |
| 图片在区域的部分位置被拉伸 | 在背向相机的面上使用了**从视图** | 换个更好的角度重新捕获，或改用**环绕**或**球面** |
| 单击一次占据了模型太多部分 | **扩散**高到越过了你预期它停下的折角 | 调低它，然后重新单击 |
