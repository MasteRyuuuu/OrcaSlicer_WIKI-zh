# 纹理置换专业模式

置换移动的是模型已有的顶点。一个普通的导入立方体只有八个顶点，所以对它应用高度图时没有可移动的东西，无论纹理深度设得多大，都看不到任何效果。在绘制和生成起伏之间，网格必须先增加三角面。

标准模式在**烘焙**内部按底部的分辨率完成这一步，从不向你展示中间网格。专业模式——[纹理置换]({{L1}})面板顶部开关的第二个位置——把同样的机制拆成一个个单独的步骤，由你自己执行和检查。

这里的一切都是可选的。绘制、图层、映射和烘焙在两种模式下完全相同。

{{T1}}

## 何时使用专业模式

- **在一个模型上试用多种纹理。** 先细化一次，然后在已经足够精细的网格上逐个试用纹理，而不必每次烘焙都为细化付出代价。
- **网格划分很差的导入模型。** 三角面尺寸从 0.05 mm 到 20 mm 不等的模型，会得到极不均匀的起伏。先用[重新网格化]({{L2}})把它变均匀。
- **控制三角面数量。** 自动选择有意给得很宽裕。如果这个零件要放进一个大项目，手动细化到纹理恰好需要的程度是值得的。
- **柔化已烘焙的结果。** [立即平滑已烘焙的网格]({{L3}})是放松已经固化的起伏的唯一方法。

## 操作顺序

这些步骤不能随意调换，因为每一步与绘制区域的交互方式都不同：

1. 如果导入模型的网格不均匀，**先重新网格化，再绘制**。重新网格化会按位置把绘制区域带过去，但在裸模型上做最干净。
2. **绘制。**
3. **使用"仅绘制区域（自适应）"进行细分**，它会把绘制区域带到更细的网格上。均匀细分会替换整个几何体，并清除所有尚未烘焙的绘制。
4. **烘焙。**

> [!WARNING]
> 均匀**细分**以及其他任何替换三角面列表的工具——包括[简化]({{L4}})——都会丢弃尚未烘焙的绘制。已经烘焙进去的起伏不受影响。

## 细分

拆分三角面，让纹理有可以置换的东西。

**仅绘制区域（自适应）**只在你绘制过的地方增加三角面。在带一小块贴花的大零件上，这就是几千个三角面和几百万个三角面的区别，而且你的绘制得以保留。关闭它时，细分是均匀的：**次数**表示把模型的每个三角面一分为四，重复这么多次——每一次都让数量变为四倍，所以三次就会把 100 k 个三角面变成 6.4 M 个。

开启自适应时：

| 控件 | 作用 |
| --- | --- |
| **跟随纹理细节** | 把三角面花在纹理真正有弯折的地方——密集分布在棱和边上，在平坦处则稀疏——而不是均匀铺开。对大多数纹理来说，能用更少的三角面得到同样的细节 |
| **最大边长** / **目标边长** | 绘制区域内没有任何三角面会大于这个值。开启**跟随纹理细节**时，它是一个基线，保证曲率检测能看到纹理；关闭时，它就是所有三角面被拆分到的尺寸 |
| **细节** | 网格与纹理所描述的形状之间允许相差多远。越小越能跟随精细细节，但消耗三角面；越大则只追随大的特征 |
| **最小边长** | 三角面尺寸的下限，使纹理中的陡峭台阶不会被无止境地追随。想要更精细的起伏就调低；如果数量在硬边处失控就调高 |
| **边缘细节** | 绘制区域轮廓处的三角面尺寸，也就是起伏回落到裸露表面的地方。如果这圈边缘看起来参差不齐就调低——它只消耗轮廓沿线的三角面。设为 0 则关闭 |
| **颜色细节** | 两种颜色交界处的三角面尺寸。只在某个图层使用[颜色]({{L5}})时显示。每个三角面只用一种耗材丝打印，所以颜色边缘的清晰度取决于沿边缘的三角面——而且没有其他步骤会在那里细化，因为颜色变化处的表面是平的 |

细化按面板底部设置的三角面预算进行。它总是先拆分最不贴合的三角面，所以即使用尽全部预算，也是花在效果最明显的地方。

- **预览细分**以线框形式显示细化的结果，而不改动模型。预览打开期间它会跟随你的绘制，并报告将会生成的三角面数量。**隐藏预览**结束预览。
- **细分**执行细化。

## 重新网格化

用尺寸接近一致的三角面重建整个模型，拆分大的三角面，合并小的三角面。

| 控件 | 作用 |
| --- | --- |
| **目标边长** | 重建模型所用的三角面尺寸。初始值为模型当前的平均值 |
| **保留锐边** | 让硬边和开放边界保持原位。不开启时，重新网格化会让顶点沿表面滑动，把每条清晰的边都磨圆——立方体回来时边缘会变得歪歪扭扭。滑块设置折角要多锐利（以度为单位）才算锐边 |
| **重新网格化** | 执行操作。几何体会被替换，你的绘制按位置带到新的三角面上。已经烘焙进去的起伏会保留 |

> [!TIP]
> 重新网格化是一种粗放的手段：它会影响整个模型，包括永远不会带纹理的部分。如果零件很大而纹理只在局部，单用自适应细分通常是更好的选择。

## 结果

这些是针对整个纹理堆叠而不是单个图层的设置，预览和烘焙都会用到。

| 控件 | 作用 |
| --- | --- |
| **置换至边界** | 让起伏一直延伸到绘制区域的边缘。关闭它会让最外圈保持平坦，这样置换严格限制在绘制区域内，但图案在边界处会变平 |
| **平滑结果** | 在应用纹理之后放松几何体，以消除低分辨率图像造成的生硬台阶。只影响被置换移动过的部分 |
| **强度** | 每一遍把顶点向相邻顶点拉近多少。数值高会很快把起伏磨圆；数值低需要更多遍，但能保留更多细节 |
| **遍数** | 运行多少遍。遍数越多，平滑扩散得越远 |
| **忽略外圈** | 让绘制区域最外圈不参与平滑。它在绘制区域外的相邻顶点永远不会移动，所以平滑这一圈会把起伏往下拖，让边界处的图案像融化了一半 |
| **立即平滑已烘焙的网格** | 立即在绘制区域内把这些设置应用到模型本身——用于已经烘焙进去的起伏。尚未烘焙的部分则由烘焙来平滑 |

> [!NOTE]
> **平滑结果**与图层自身的**平滑**是针对相似问题的不同工具。平滑在使用之前模糊*图像*，所以会让各处都损失精细细节。平滑结果在之后放松*几何体*，所以会磨圆网格无法干净表现的台阶。生硬、颗粒感强的源图像适合用前者；有台阶感的低分辨率图像适合用后者。
