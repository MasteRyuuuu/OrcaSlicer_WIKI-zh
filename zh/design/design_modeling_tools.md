# 建模工具

[设计选项卡]({{L2}})中把[草图]({{L1}})变成实体的工具，以及这些工具所依附的参考几何。每个工具都作用于当前已选中的内容，并且都会成为特征树中的一个特征，之后可以再编辑。

{{T1}}

## 添加材料

| 工具 | 按键 | 作用 |
| --- | --- | --- |
| 拉伸 | `Shift + E` | 拉伸轮廓，或者推拉实体上已有的面 |
| 旋转 | `Shift + R` | 绕轴旋转轮廓 |
| 扫掠 | `Shift + W` | 沿路径扫掠轮廓，路径也可以是螺旋线，用于制作弹簧和螺旋推进器 |
| 放样 | `Shift + L` | 在两个或更多轮廓之间生成蒙皮 |
| 加厚 | — | 把实体的一个面偏移成一块薄板，作为新实体 |
| 加强筋 | — | 从开放的草图线生长出一道加强壁，并与实体融合 |

拉伸提供给定深度、对称、两侧、完全贯穿和成形到面几种终止条件，还可以为侧壁设置拔模角度。其结果可以添加到现有实体、从中减去、与之相交，或者新建一个实体。

> [!NOTE]
> 没有去除任何材料的减法会报告为错误，而不会悄悄地"成功"。

## 曲面

曲面实体是没有厚度的曲面，适用于更容易先做成蒙皮、再实体化的形状。

| 工具 | 按键 |
| --- | --- |
| 拉伸曲面 | `Shift + G` |
| 旋转曲面 | `Shift + J` |
| 放样曲面 | `Shift + O` |
| 填充曲面 | `Shift + Q` |
| 偏移曲面 | `Shift + U` |
| 加厚曲面 | `Shift + V` |

加厚曲面是把曲面实体变成可打印实体的方法。

## 修饰

| 工具 | 按键 | 作用 |
| --- | --- | --- |
| 圆角 / 倒角 | `Shift + F` | 对选取的边倒圆角或倒角 |
| 拔模 | `Shift + D` | 让选取的面按一定角度倾斜 |
| 抽壳 | `Shift + K` | 把实体挖空到指定的壁厚，并在选取的面上开口 |
| 删除面 | — | 删除面并修复实体，可以用来去掉导入零件上的某个特征 |

## 孔和螺纹

**孔**（`Shift + H`）可以钻出简单孔、沉孔和埋头孔，以选取的面为中心，或放置在某个平面上。它带有 ISO 和 ANSI 标准表，所以你可以直接要一个 M6 通孔，而不必自己计算直径。

**螺纹**（`Shift + T`）在孔内或轴上切出真实的螺旋螺纹。

## 放置

在不改变形状的情况下移动实体的操作：**变换**（`Shift + Y`）移动和旋转实体，**镜像**（`Shift + Z`）关于一个平面镜像实体，**配合**把一个实体放到另一个实体上（参见[装配]({{L3}})）。

## 组合

**布尔**（`Shift + B`）对两个实体求并集、差集或交集。**切除**（`Shift + X`）用平面分割实体。**阵列**（`Shift + N`）沿直线、圆周或曲线重复一个实体。

## 参考几何

基准特征不包含任何材料，它们的作用是给后续特征提供依附对象。

| 特征 | 按键 | 构建方式 |
| --- | --- | --- |
| 平面 | `Shift + P` | 偏移、倾斜、中间平面、相切、两条边，或与某个面重合 |
| 轴 | `Shift + A` | 两点、面法线、圆柱中心线、两个平面的交线，或一条边 |
| 坐标系 | `Shift + C` | 一个完整的坐标框架，由一个世界坐标点，或由一个面加一条方向边构建 |
| 螺旋线 | — | 供扫掠使用的螺旋曲线 |
| 投影 | — | 把实体的边投影到平面上，作为草图几何 |

> [!TIP]
> 使用坐标系工具时，多单击一次选取方向边是值得的。不选方向边时，坐标框架的 X 轴取自面的第一条边，结果虽然可重复，但不一定是你想要的方向。

## 装配

**配合**对齐两个坐标系，并把一个实体移到另一个实体上。有五种配合类型：

| 类型 | 保留的自由度 |
| --- | --- |
| 紧固 | 无——六个自由度全部锁定 |
| 平面 | 在平面内滑动 |
| 旋转 | 绕轴旋转 |
| 滑块 | 沿轴滑动 |
| 圆柱 | 旋转和滑动 |

**检查干涉**会报告每一对相互重叠的实体以及重叠的体积，让碰撞成为一个具体的数字，而不只是一种印象。只是相互接触的实体没有包围任何体积，不会被报告。

配合连接器绘制为一个小面，一眼就能看出其朝向。**将配合连接器绘制为面**（偏好设置 → 控制 → 相机）可以关闭这一显示方式，改用带滚转象限的传统圆盘。

> [!NOTE]
> 配合按创建顺序依次应用，而不是一起求解，并且尚未实现配合限位。请从固定的实体开始，由内向外构建装配体。

## 变量与表达式

定义命名变量，并用它们驱动尺寸。任何数值字段都可以输入表达式，例如 `width/2` 或 `wall*3`，重新计算时所有内容都会重新求值。修改一个变量，整个模型都会随之更新。

## 特征树

特征树是可编辑的历史，而不只是一份日志。选择一个特征会以创建它时相同的在几何体上交互的方式重新打开它，`F2` 重命名，`Del` 删除。每次更改都会从头重放整个配方，所以在模型早期设置的尺寸会重建其后的所有内容。`Ctrl + Z` 和 `Ctrl + Shift + Z` 在整个选项卡范围内撤销和重做。
