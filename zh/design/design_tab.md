# 设计选项卡

设计选项卡是 OrcaSlicer 内置的、以草图为先的参数化 CAD 环境。绘制草图、添加约束、把它变成实体、进一步细化，然后直接送到盘上——无需切换到其他应用程序，再通过 STL 导回来。

你构建的是一份**配方**，而不是一个网格。每个操作都会成为特征树中的一个特征，任何内容发生变化时，整棵树都会从头重放一遍，所以修改二十步之前设置的某个尺寸，会重建其后的所有内容。这份配方保存在 3MF 项目文件中，因此重新打开项目时恢复的是可编辑的模型，而不是固定死的网格。

{{T1}}

该选项卡的其余内容见[草图]({{L1}})、[建模工具]({{L2}})和[设计快捷键]({{L3}})。

## 启用设计选项卡

这个选项卡是实验性的，**默认关闭**，所以全新安装时根本不会显示它。

1. 打开**偏好设置 → 常规 → 特性**。
2. 勾选 **CAD 功能（实验性）**。
3. 重启 OrcaSlicer。选项卡在启动时创建，所以要到下次启动才会出现。

开启后，[准备]({{L4}})工具栏中还会增加两个 CAD 工具——**草图**和**标准模型**——它们可以不经过设计选项卡，直接把实体放到盘上。与选项卡本身一样，功能关闭时它们也会隐藏。

另有两项偏好设置属于这个选项卡：

| 偏好设置 | 位置 | 作用 |
| --- | --- | --- |
| 自动闭合草图环 | 常规 → 特性 | 把相距 0.001 mm 以内的草图端点视为同一个连接点，并把环焊接闭合。关闭时，只有完全重合的端点才会连接，所以有微小缺口的环会保持开放 |
| 将配合连接器绘制为面 | 控制 → 相机 | 把配合连接器绘制成一个小面，而不是带有滚转象限的传统圆盘。仅在启用 CAD 功能时列出 |

> [!NOTE]
> 这项功能正在积极开发中。预计它在不同的每夜构建版本之间会有变化，请为你在意的项目保留备份。

## 入门

1. 打开**设计**选项卡。
2. 在视口中单击一个面或基准面，然后按 `Shift + S`（草图）。操作菜单会打开，其中列出草图工具。
3. 绘制一个封闭轮廓，然后在浮动操作栏中确认草图。
4. 选中草图后，按 `Shift + E`（拉伸）。
5. 按**提交到盘**（`Ctrl + Shift + P`），把实体交给[准备]({{L5}})。

> [!TIP]
> 并非一切都要从零开始建模。[导入 STEP]({{L6}}) 会带入一个真正的实体，它的面和边可以像在这里绘制的任何东西一样进行圆角、抽壳和切除。

## 状态栏

工具栏下方的这一行说明当前工具正在等待什么；当某个操作没有反应时，首先应该看这里：

- 没有选取平面时，它显示*在视口中单击一个面或基准面，然后选择草图工具*。
- 选取平面后，它显示*正在 &lt;面&gt; 上绘制草图——请选取工具*。
- 当某个操作被拒绝时，会在这里说明原因。

## 选择

先选择，再由工具使用所选内容：先指向几何体，再选择要执行的操作。

- 单击一次左键选中光标下的对象。不会在面、边和实体之间循环切换。
- 在角点附近单击会选中角点，而不是它后面的面。
- 按住左键拖动会拉出一个框选框，框选会选中整个实体。
- 开放的草图线可以被单击选中，即使它位于某个区域的边界上。
- 双击草图笔画可以编辑它。
- 编辑尺寸值会更新该尺寸，而不会在旁边再添加一个尺寸。
- 单击空白处会清除选择。它绝不会提交任何内容。

## 操作菜单

在几何体上单击右键，并在不移动鼠标的情况下松开，就会打开操作菜单，其中列出适用于所选对象的操作。用右键拖动来旋转相机不会打开它，而左键单击仍然只负责选择，所以指点对象时界面保持安静。也可以用键盘上的 `Menu` 键或 `Shift + F10` 打开菜单；在面或平面上按"草图"时，它也会自动打开。

菜单始终按相同的顺序显示相同的八个类别，所以一个操作无论出现在哪里，位置都保持不变：

| 行 | 类别 | 包含的内容 |
| --- | --- | --- |
| 1 | 创建 | 在面上绘制草图、编辑文字 |
| 2 | 添加材料 | 拉伸、加厚、组合 |
| 3 | 移除 | 孔、抽壳、切除、分割、螺纹 |
| 4 | 修饰 | 圆角、倒角、拔模 |
| 5 | 重复 | 阵列、镜像 |
| 6 | 变换 | 移动、对齐、配合 |
| 7 | 参考 | 平面、轴、投影、测量 |
| 8 | 修改 | 编辑、重命名、颜色、删除 |

- 只有一个适用操作的类别会直接显示该操作；有多个适用操作时，它们会收进以类别命名的子菜单中。
- 没有任何适用操作的类别会**在原位置以灰色显示，并附上原因**——例如*创建——在视口中单击一个面或基准面，然后选择草图工具*。各行从不隐藏或重新排序，所以这个菜单同时也是一张地图，告诉你这个选项卡能做什么、你需要先做什么。
- 在草图内部，菜单提供草图操作；在草图之外，它提供特征操作。
- 每一行都显示其快捷键，所以菜单本身会教你用哪个键可以不再需要菜单。

作用于整个文档而不是所选对象的操作留在工具栏上，从不出现在菜单中：导入 STEP、导入网格、文字、SVG、导出 STEP、提交到盘、撤销、重做、变量、剖面视图、原点平面和世界坐标轴。

## 视图控制

| 控件 | 按键 | 作用 |
| --- | --- | --- |
| 适配视图 | `Home` | 等轴测视图，并缩放到适合模型 |
| 原点平面 | `P` | 显示或隐藏三个原点平面 |
| 世界坐标轴 | `A` | 显示或隐藏世界坐标轴 |
| 剖面视图 | `X` | 隐藏模型的一半以查看其内部 |
| 移动剖切面 | `Page Up` / `Page Down` | 剖面视图开启时，移动剖切平面 |
| 翻转剖切 | `F` | 剖面视图开启时，改为保留另一半 |
| 选择底面 | `F` | 没有开启剖面视图时，把选取的面平放到热床上 |
| 显示或隐藏热床 | `Ctrl + Shift + B` | 打开草图时打印机热床会淡化显示，这样就不会把盘上的网格误当作草图网格 |

## 导入和导出

**导入 STEP**（`Shift + I`）带入的是真正的 B-rep 实体，而不是网格。它的面和边可以像在这个选项卡中建模的任何东西一样进行圆角、抽壳和切除。

**导入网格**（`Shift + M`）把 STL 或 OBJ 转换为 B-rep 实体，并报告转换结果：结果是封闭的实体还是开放的壳体，以及有多少条边界边和非流形边。

> [!WARNING]
> 大型网格会变成一个面数很多的实体，编辑起来很慢。导入器会在你确认之前给出警告。

**导出 STEP** 把模型写出供其他 CAD 应用程序使用，输出的是真正的 B-rep 几何体，而不是三角化的结果。

## 提交到盘

**提交到盘**（`Ctrl + Shift + P`）把实体交给[准备]({{L7}})进行切片。特征配方保存在 3MF 项目中，所以重新打开项目时恢复的是可编辑的模型，而不是固定死的网格——零件在切片之后仍然可以重新修改尺寸。

## 限制

- **加强筋**需要一个包含明确开放线条的草图。参数化矩形草图不包含单独的图元，因此加强筋不能使用它。
- **配合**按创建顺序依次应用，而不是一起求解，因为背后没有 3D 装配求解器。配合限位尚未实现。
- 尚不支持移动或替换现有实体的面。
