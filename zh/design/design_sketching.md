# 草图

草图是在基准面或现有实体的平面上绘制的二维轮廓。它几乎是[设计选项卡]({{L1}})中一切操作的起点：轮廓通过[建模工具]({{L2}})变成实体，之后仍然保持可编辑。

{{T1}}

## 开始绘制草图

1. 单击要在上面绘制的面或基准面。
2. 按 `Shift + S`，或者从操作菜单中选择**草图**。草图会在你第一次单击的那个面上打开。
3. 选择一个工具——单个字母键、工具栏或操作菜单都可以——然后开始绘制。

每个工具都会在状态栏中说明下一步需要什么，例如*圆：单击圆心，然后单击确定半径*。

## 草图环境

草图打开时有三处变化，让你一眼就能分清当前模式：

- 视口顶部会出现一条横幅，显示草图名称，并提醒你按 `N` 可正视于平面，以及从工具栏退出草图。
- 打印机热床会淡化显示，因为盘上的网格和草图网格看起来很像，把一个误认成另一个，正是轮廓被画在错误参照上的原因。按 `Ctrl + Shift + B` 可以让热床重新显示。
- 只要草图处于打开状态，单个字母键就用来驱动草图工具。参见[设计快捷键]({{L3}})。

随时按 `N` 可以正对草图平面查看，同时保持当前的缩放。

## 图元

| 图元 | 变体 |
| --- | --- |
| 直线 | 单条直线、多段线 |
| 矩形 | 角点、中心、斜向、圆角 |
| 圆 | 圆心和半径、两点、三点 |
| 圆弧 | 圆心、三点、相切 |
| 椭圆 | 椭圆、椭圆弧 |
| 多边形 | 内接、外切 |
| 槽口 | 直槽、圆弧槽 |
| 样条曲线 | 通过控制点的 B 样条 |
| 点 | 单个点 |
| 文字 | 草图平面上的文字 |

按 `Q` 可以把接下来绘制的图元作为**构造几何**，或者把所选图元在构造几何和实际几何之间转换。构造线用于辅助草图，在轮廓变成实体时会被忽略。

## 编辑

| 工具 | 按键 | 作用 |
| --- | --- | --- |
| 修剪 | `T` | 把一段线修剪到最近的交点 |
| 延伸 | `X` | 把直线或圆弧延伸到它会相交的对象 |
| 偏移 | `O` | 在一定距离处复制一个图元 |
| 镜像 | `M` | 先选取一条轴，再选取要镜像的图元 |
| 圆角 | `F` | 把两条直线之间的转角倒圆 |
| 倒角 | `H` | 把两条直线之间的转角切成斜角 |
| 尺寸 | `D` | 标注两点之间或单个图元的尺寸 |
| 数值 | `V` | 输入所选对象的定义数值——直线的长度、圆弧的半径、圆的直径，或两个图元之间的角度 |

还可以通过工具栏移动、旋转、缩放图元，或以线性阵列、圆周阵列的方式重复图元。

## 约束与尺寸

按 `K` 结束当前工具并进入约束模式。可用的几何约束有：重合、共线、水平、竖直、平行、垂直、相切、同心、中点、等长、等半径、对称和固定。尺寸约束有：距离、水平距离、竖直距离、角度、半径和直径。

求解器会在你操作时报告剩余的自由度，并在草图完全约束时，或新约束与已有约束冲突时告诉你。

> [!TIP]
> 先约束形状，再标注尺寸。因为约束了水平和竖直而保持方正的轮廓，在尺寸改变时仍然方正；只是因为画得仔细才方正的轮廓则不然。

## 完成草图

- 在浮动操作栏中单击**确定**，或者按 `Enter`，完成并保留草图。
- 在操作栏中单击**取消**会丢弃草图；如果有几何体会丢失，会先询问。
- `Esc` 从不会毁掉你的工作。它依次执行以下其中一步——关闭打开的数值框、丢弃正在绘制的图元、把已激活的工具退回到"选择"，或者清除选择——每次一步，按此顺序进行。含有几何体的草图只能通过"确定"或"取消"退出。
- 在草图中按 `Ctrl + Z` 会移除最后绘制的图元。`Del` 或 `Backspace` 删除所选图元。
- 如果草图中的图元不构成任何封闭的线框，会给出一条提示信息并失败，而不会生成一个默认形状。**自动闭合草图环**（偏好设置 → 常规 → 特性）决定这项检查有多宽容：开启时，相距 0.001 mm 以内的端点会被焊接成一个连接点；关闭时，只有完全重合的端点才会连接，所以有细微缺口的环会被报告为开放。

## 重新打开草图

草图始终保持可编辑。在特征树中选择一个草图，即可重新打开它，其尺寸仍然有效；修改某个数值，基于它构建的所有特征都会重建。在视口中双击草图笔画可以直接编辑该图元。
