# 设计快捷键

[设计选项卡]({{L1}})有两套按键映射，当前生效的是哪一套，取决于是否打开了草图：

- **打开了草图**——单个字母键驱动[草图工具]({{L2}})。
- **没有打开草图**——`Shift` 加字母键驱动[建模工具]({{L3}})，单个字母键驱动视图。

在输入框中输入时，快捷键永远不会被拦截；操作菜单中每个操作旁边都会显示其按键。这些按键是固定的——与应用程序中的其他快捷键不同，它们不能重新分配。

## 草图工具

打开草图时可用。

| 按键 | 工具 |
| --- | --- |
| `L` | 直线：单击起点，然后单击终点 |
| `R` | 矩形：单击两个对角 |
| `C` | 圆：单击圆心，然后单击确定半径 |
| `A` | 圆弧：依次单击起点、终点，然后单击一个点 |
| `S` | 槽口：中心线的两个端点，然后是端部半径 |
| `E` | 椭圆：中心、长轴端点、短轴上的点 |
| `B` | 样条曲线：单击控制点 |
| `P` | 点：单击放置 |
| `G` | 多边形：单击中心，然后单击一个顶点 |
| `D` | 尺寸：单击 2 个点或一个图元 |
| `T` | 修剪：单击要修剪的线段 |
| `X` | 延伸：单击要延伸的直线或圆弧 |
| `O` | 偏移：选取一个图元，拖动设置距离 |
| `M` | 镜像：选取轴，然后选取图元 |
| `F` | 圆角：选取两条直线，设置半径 |
| `H` | 倒角：选取两条直线，设置距离 |
| `V` | 数值：输入所选对象的定义数值 |
| `K` | 约束：结束当前工具并进入约束模式 |
| `Q` | 构造：把接下来绘制的图元作为构造几何，或转换所选图元 |
| `N` | 正视于草图平面 |
| `Enter` | 完成草图 |
| `Esc` | 关闭数值框、丢弃正在绘制的图元，或退出已激活的工具 |
| `Del` / `Backspace` | 删除所选草图图元 |
| `Ctrl + Z` | 移除最后绘制的图元 |

## 视图与文档

没有打开草图时可用。

| 按键 | 操作 |
| --- | --- |
| `Home` | 等轴测视图，并缩放到适合模型 |
| `P` | 显示或隐藏原点平面 |
| `A` | 显示或隐藏世界坐标轴 |
| `X` | 开启或关闭剖面视图 |
| `Page Up` / `Page Down` | 剖面视图开启时，移动剖切平面 |
| `F` | 剖面视图开启时翻转剖面，否则把选取的面平放到热床上 |
| `Ctrl + Shift + B` | 显示或隐藏打印机热床 |
| `Ctrl + Shift + P` | 提交到盘 |
| `Menu` / `Shift + F10` | 打开当前所选对象的操作菜单 |
| `F2` | 重命名所选特征 |
| `Del` | 删除所选特征 |
| `Esc` | 清除选择 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Shift + Z` / `Ctrl + Y` | 重做 |
