# "发布 3MF"有什么用？

**发布 3MF** 把你选择的设置嵌入 3MF 文件中，让模型和它的配置一起分享出去。

与保存完整快照的**保存项目**不同，发布时由你精确挑选打印所需的设置，再把它们打包在一起。

其他用户打开这个文件时，他们自己的设置不会被覆盖；发布的设置只是叠加应用在上面。

## 如何识别已发布的 3MF 文件？

从 OrcaSlicer 发布的 3MF 文件左上角会显示一个小徽标，文件标题旁边还会有绿色的 <span style="background-color: #009688; color: #FFFFFF; margin-right: 4px; padding: 0 4px;">PUB</span> 字样。

## 打开已发布的 3MF 文件

像打开任何 3MF 文件一样打开它即可！

你的打印机设置不会改变，打印该模型所需的耗材丝/工艺设置会直接叠加应用在你现有的设置之上。
