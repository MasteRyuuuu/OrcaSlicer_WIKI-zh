# 资源纹理

`orca.resource_texture` 模块为以资源包形式提供高度图纹理的插件提供 `ResourceTexturePluginCapabilityBase`。

| 基类 | `get_type()` 返回 | 必需的方法 | 调用者 |
|---|---|---|---|
| `orca.resource_texture.ResourceTexturePluginCapabilityBase` | `ResourceTexture` | `get_name()`、`get_texture_dir(self) -> str` | 功能被具体化时由 OrcaSlicer 调用 |

生命周期钩子 `on_load()` / `on_unload()` 是可选的，每项功能都可以使用（默认什么也不做）。

## 最小结构

{{C1}}

`get_name()` 是资源包的显示名称，所以在已加载的同类资源包中必须唯一（参见[注册]({{L1}})）。

## 纹理目录

`get_texture_dir()` 返回一个目录，宿主会扫描其中的图像。

| 规则 | 细节 |
|---|---|
| 格式 | `.png`、`.jpg`、`.jpeg`、`.bmp`，不区分大小写 |
| 深度 | 一层，不递归；子目录中的图像不会列出 |
| 位置 | 解析后的目录必须位于插件自己的文件夹内。位于其外的目录会被拒绝；资源包内解析到外部的符号链接会被跳过 |
| 文件数量上限 | 最多列出 64 张图像 |

`get_texture_dir()` 在功能被具体化时、在持有 GIL 的情况下运行一次，结果会被缓存。目录的变化在重新加载后才生效，插件保持加载期间不会生效。

如果目录为空、不存在、无法读取或位于插件文件夹之外，损失的只是该资源包的纹理：插件仍会加载，只是该资源包被排除在外。原因会写入会话日志。

## 打包

请发布 wheel（`.whl`）。安装时只会复制一个入口文件，所以 `.py` 插件无法携带同级的图像；wheel 是一个文件，加载器会按需解压它，图像位于包自己的目录中。参见 [wheel（`.whl`）插件]({{L2}})。

## 生命周期

宿主会跟踪已加载并启用的资源包。功能加载并启用后，资源包中的纹理就可以在 OrcaSlicer 中使用；功能被禁用、卸载或删除时，纹理随之移除。不需要重启。已经嵌入了某个资源包纹理的内容会保留该纹理，因为它保存了图像数据的副本。
