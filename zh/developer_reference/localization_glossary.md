# 翻译术语表

OrcaSlicer 关键术语的跨语言参考，用于让每种语言内部的翻译保持**一致**。基准列是英文（即 `msgid`）。

本页是[本地化与翻译指南]({{L1}})的配套资料：  
在翻译反复出现的术语之前，先在这里查一查既定的译法，让同一个英文单词在一种语言中始终以同样的方式呈现。

> [!NOTE]
> 中文版的大表只保留了英文、说明、简体中文（zh_CN）和繁体中文（zh_TW）几列，说明也已译成中文。其他语言的译法请查看英文原页。

## 保留英文（不翻译）

这些术语在基本上所有语言的 `msgstr` 中都原样书写。  
使用非拉丁文字的语言（ja、ko、zh、ru、uk、th）保留拉丁字母的缩写/品牌名称，但可以加上翻译后的说明词。对于本来就是普通单词的条目，这些语言则遵循各自地区的标准，用本地文字书写该术语——音译（ja ホットエンド、uk *Хотенд*、ru *Хотэнд*），或使用本土的对应词（zh_CN 热端）；实际采用的形式请查看[翻译对照表]({{L2}})。

| **CF**、**GF**（以及 `-CF` / `-GF` 后缀） | 混入基础聚合物中的*碳纤维*和*玻璃纤维*增强材料（例如 PLA-CF、PA-GF）。保留英文缩写，以便与材料名称一致。 |

### 更新术语表

[翻译对照表]({{L5}})是**自动生成**的。

这些文件以**制表符分隔**，所以一个单元格就是两个制表符之间的全部文本，说明中的逗号或引号无需转义。它们可以在 Excel、LibreOffice 和 Google Sheets 中作为表格打开——保存时只需保留制表符，并且绝不要在单元格内输入制表符。

## 各语言的特别说明

这里供翻译者写明各自翻译的一些独特之处。

### 俄语（ru）

- **Nozzle**——使用 *Сопло*（喷嘴尖端）。*Экструдер* 是拓竹沿用的旧标签，指整个工具头；这两种含义正在通过 `msgctxt` 拆分，所以**不要**用 *Экструдер* 表示喷嘴尖端。
- **Hotend**——*Хотэнд*，用 **э** 拼写（不是 *Хотенд*，那是乌克兰语的形式）。
- **Toolhead**——绝不用 *головка*，那是二维打印机的用词。运动组件请使用 *[печатающая] голова* / *каретка*（*Парковка головы*、*параллельных печатающих голов*）。要与它所承载的可更换模块区分开：在换工具头/换热端的打印机上，那个模块是热端（*насадка*），而 *инструмент* 属于 `tool` / `tool change` 相关的字符串。正在进行的讨论参见 [PR #14970]({{L6}})。
- 有几个单词的界面字符串是同形异义词，在不同上下文中需要不同的俄语形式，现在都带有 `msgctxt`；请分别翻译每个上下文：
    - **Cut**——*Разрезать*（切割工具）/ *Вырезать*（剪贴板，Ctrl+X）
    - **Left** / **Right**——*Слева* / *Справа*（相机方向）/ *Левое* / *Правое сопло*（喷嘴侧）
    - **Smooth**——*Сгладить*（动作）/ *Плавный*（延时摄影模式）
    - **Edit**——*Правка*（菜单）/ *Изменить*（动词）
    - **Assemble**——*Объединить в сборку*（动作）/ *Собрать*（装配工具）
    - **End**——保留 *End*（键盘按键）/ *до конца*（层范围）

### 土耳其语（tr）

已在 [PR #15119]({{L7}}) 中确定，并在 [PR #15309]({{L8}}) 中继续完善；后者完成了 `Jerk` 的全面替换、重新确定了对象实例的术语，并统一了 `Mirror`：

- **Jerk**——在所有地方都译为 *Sarsıntı*。`Maximum jerk of the X/Y/Z/E axis` 这几个字符串在括号中加上了英文单词（*maksimum sarsıntısı (Jerk)*），这样没有问题；`set_accel_and_jerk()` 是代码标记，保持原样。
- **Instance**——对象含义译为 *Eş kopya*（`Add instance`、`Set number of instances`、`Instance manipulation`、`Fill bed with instances`）。之所以选它而不是单独的 *Kopya*，是为了避免与克隆/副本这一系列冲突：`Fill bed with instances` 是 *Yatağı eş kopyalarla doldur*，`Fill bed with copies` 是 *Yatağı kopyalarla doldur*——两个不同的操作，两个不同的词。
- **Instance（应用程序）**——*Örnek*，绝不用 *Kopya* 或 *Eş kopya*。这里指 `Allow only one OrcaSlicer instance`、`Current Instance`、`Current Instance Path: `、`Failed to launch a new instance.` 以及打印主机字段，其中的实例是一个运行中的程序，而不是盘上的一个摆放。
- **Clone**——*Klon*（`Clone`、`Clone Selected`、`Clone Objects`）。既然对象实例使用 *Eş kopya*，克隆系列就可以在其 `copies` 字符串中保留 *kopya*。仍待处理：`Clone copies of selections` 译成了 *Seçimlerin kopyalarını kopyala*（"复制副本"），需要改用 *klon* 的措辞。
- **G-code**——保留英文并带连字符，土耳其语的格词尾用撇号连接（*G-code'u dışa aktar*、*G-code'un*、*G-code'a*、*G-code'ları*）；复合词尾直接去掉（*G kodu dosyaları* → *G-code dosyaları*）。这在 [PR #15309]({{L9}}) 中进行了全面替换，转换了 108 个拼写为 *kod* 的条目（14 种变体：*G kodu*、*G-kodu*、*G-kod*、*G Kodu*、*G-Kod*、*G kod*……），另外还有 28 个在正文中使用了小写的单独 *gcode*。绝不能转换的：`.gcode` / `.gcode.3mf` 文件扩展名，以及嵌入了该标记的设置 ID（`layer_change_gcode`、`before_layer_change_gcode`）。
- **Mirror**——*Aynala*，动词，包括简短的 `Mirror` 输入标签；不用 *Ayna*（名词），也不用读起来像"投影/反射"的 *yansıt*。
- **Bed / Build plate**——热床用 *Yatak*，打印板用 *Plaka*。还有七个字符串中留着第三个词 *Tabla*，它们各自属于前两者之一：`Bed adhesion`、`Excluded bed area` 以及首层加速度的提示说明属于 *Yatak*；`Delete all objects on the current plate`、`Cannot send a print job for an empty plate.`、`max triangle count per plate for slicing` 和 `max slicing time per plate in seconds` 属于 *Plaka*。
- 让标签和提示说明使用同一个术语。如果提示说明列举了各个选项——比如层内顺序的提示说明——请严格按照每个选项自身 msgid 的译法引用它们（*Varsayılan*、*Nesne listesi olarak*、*Hepsinin en iyisi (en kısa yol)*、*Yılankavi*），让文字与下拉列表保持一致。

### 法语（fr）

- **Prime tower / Wipe tower**——两个英文名称都译为 *Tour d’amorçage*（在 [PR #396]({{L10}}) 中确定），包括 `Wipe tower type`、`Wipe tower volume` 以及擦拭塔成本相关的字符串。*Essuyage* 保留给喷嘴的 `Wipe`（`Wipe speed`、`Wipe distance`），`Belt purge tower` 则用 *Tour de purge du tapis*。
- **Chamber**——标签以及 `Chamber temperature` 中都用 *Caisson*。不再使用 *Chambre*。
- **Gizmo**——在所有小工具字符串中都用 *gizmo*（`Entering Cut gizmo` → *Entrée dans le gizmo Couper*），而不用 *outil*。
- **颜色名称**——CSS 和 Orca 调色板中的名称要翻译（*Bleu ciel*、*Vert forêt*）。RAL 名称遵循官方的法语 RAL 名称，名词在前（*Bleu vert*、*Rouge pourpre*）。
