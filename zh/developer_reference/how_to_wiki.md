# 如何为 Wiki 做贡献

本指南说明如何为 OrcaSlicer wiki 做贡献。

OrcaSlicer 的 wiki 由 [OrcaSlicer WIKI 仓库]({{L1}})中的文件自动生成。  
如果想提出小的修改或改进建议，请[在该仓库中提交 issue]({{L2}})。  
如果你更愿意自己动手编辑，请按照本指南中的最佳实践创建拉取请求（PR）。

我们鼓励开发者和用户通过更新现有页面、添加新内容来做贡献。这有助于让文档保持准确和有用。  
添加新功能时，请考虑同时更新 wiki，让用户能看到最新的指导。

{{T1}}

## Wiki 结构

Wiki 的每个页面都是位于 [OrcaSlicer_WIKI 仓库]({{L3}})中的一个 Markdown 文件。  
Wiki 分为若干部分，分别涵盖项目的不同领域。

### 首页

首页是 OrcaSlicer wiki 的起点。从这里可以进入与项目相关的各个部分和主题。

创建新页面或新部分时，请在首页相应的类别下链接它。  
首页目前按以下几个顶层条目组织内容：

- {{I1}} [打印机设置]({{L4}})
- {{I2}} [材料设置]({{L5}})
- {{I3}} [工艺设置]({{L6}})
- {{I4}} [准备]({{L7}})
- {{I5}} [校准]({{L8}})
- {{I6}} [开发者部分]({{L9}})

每个部分可以有多个页面，分别涵盖具体的主题。例如，[工艺设置]({{L10}})部分包括关于[质量]({{L11}})、[支撑]({{L12}})和[其他]({{L13}})的页面。

### 文件命名与组织

创建新页面时，请遵循以下文件命名约定：

- 使用唯一的文件名，避免冲突。
- 使用能反映页面内容的描述性名称。
- 文件名使用 snake_case（例如：`how_to_wiki.md`）。
- 如果页面属于某个部分，请加上能说明这一点的后缀（例如，校准页面应以 `-calib.md` 结尾，如 `flow_ratio_calib.md`）。
- 在适用时把文件放在相应的子目录中（例如：与校准相关的内容放在 `calibration/` 中）。

## 格式与风格

为 wiki 做贡献时，请遵循以下风格和格式约定。

### Markdown 格式

Wiki 使用标准 Markdown 语法进行格式化，并力求在所有页面中保持一致的风格。避免使用原始 HTML 标签，优先使用 Markdown 格式。

确保缩进一致，尤其是代码块和列表。

关于 Markdown 语法的更多信息，请参阅 [GitHub Markdown 指南]({{L19}})。

## 图片

我们鼓励使用图片来提升 wiki 内容的清晰度和质量。图片有助于说明概念、提供示例并提高可读性。

> [!CAUTION]
> 除非获得了适当的许可，否则不要使用来自第三方来源的图片。

### 图片来源

#### OrcaSlicer 资源

使用 OrcaSlicer 仓库中位于 `\resources\images` 的资源文件夹里的图片。这些图片的设计与应用程序界面相匹配，能保持一致性。

#### Wiki 图片

使用或添加 [OrcaSlicer_WIKI 仓库]({{L22}}) `images/` 目录中的图片。  
那里有 wiki 中已经使用过的图片，例如截图、示意图和图标。

##### 图片命名

- 使用清晰、能反映图片内容的描述性文件名。
- 对于特定小节的图片，请在文件名中包含小节名称或其首字母缩写（例如压力提前的图片使用 `pa-[description].png`）。

##### 图片存放位置

- 通用图片应放在 `images/` 目录中。
- 特定小节的图片应存放在相应的子目录中（例如校准内容放在 `images/calibration/` 中）。

> [!TIP]
> 你可以使用图形界面中所用的 `\resources\images` 图片。

### 避免以下做法

- 相对路径
- GitHub Assets/user-content/user-images 的 URL
- 来自临时或不可靠托管服务的外部图片链接
- 包含个人信息或敏感信息的图片
- 用图片表示可以用文字表达的内容，例如公式或代码——请改用 Markdown 语法或 Mermaid/数学公式格式。

> [!NOTE]
> 提交特定小节的图片时，请遵循命名约定和目录结构。

### 图片裁剪与突出显示

为确保清晰：

- 裁剪图片，聚焦于相关区域。
- 使用简单的标注（箭头、圆圈、矩形）突出重要部分，但不要让图片过于杂乱。

### 推荐格式

- **JPG：** 适合照片。由于压缩伪影，避免用于带文字或精细细节的图片。
- **PNG：** 适合截图或带透明度的图片。确保在浅色和深色模式下都有足够的对比度。
- **SVG：** 尽可能优先使用。SVG 支持主题适配（浅色/深色模式），非常适合图标和示意图。

## 组织内容

每个页面都应当有明确的目标。在简短的介绍之后，选择适合内容的结构：

- **分步指南：** 用于有先后顺序的操作（例如校准）。
- **基于界面的参考：** 当不需要先后顺序时，按照 OrcaSlicer 的界面描述各项设置。

例如：先讲解**层高**，再讲解**首层层高**，因为前者是全局的，而后者只适用于第一层。
