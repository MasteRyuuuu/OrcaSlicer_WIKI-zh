# 入门

插件为 OrcaSlicer 增加额外的功能。插件在"插件"窗口中管理。

- [本地插件]({{L1}})
- [云端插件]({{L2}})
- [插件类型]({{L3}})
- [管理插件]({{L4}})

## 打开插件窗口

1. 打开主菜单。
2. 单击**插件**。

{{I1}}

插件窗口显示已安装和可用的插件。上方的表格列出插件，下方区域显示所选插件的详细信息。

详细信息区域包含以下选项卡：

- **插件信息**——来源、作者、版本、功能和状态。
- **描述**——插件作者提供的信息。
- **配置**——所选插件各项功能的配置。
- **更新日志**——可用的版本历史。
- **诊断**——加载和错误信息。

每项功能都有一份配置。OrcaSlicer 默认提供一个 JSON 编辑器；插件也可以改为提供自定义的配置页面。面向插件作者的 API 请参见[插件配置]({{L5}})。

{{I2}}

使用分体式的**浏览插件**按钮选择添加插件的方式：

- **浏览插件**打开云端插件浏览器。
- **安装本地插件**从你的电脑上安装插件文件。

{{I3}}

> [!NOTE]
> 只安装来自你信任的来源的插件。插件可以访问你的文件并介入打印工作流程。
