# 云端插件

云端插件是关联到你的 OrcaCloud 账户的插件。可以在云端插件浏览器中订阅它们，然后在 OrcaSlicer 中安装并激活。

## 浏览云端插件

1. 登录 OrcaCloud。
2. 打开**文件** > **插件**。
3. 单击**浏览插件**。
4. 在云端插件浏览器中订阅你想要的插件。
5. 返回 OrcaSlicer；如果插件列表还没有更新，单击**刷新**。

已订阅的插件会带有**已订阅**来源标签。已订阅的插件在你激活之前可能显示**未安装**和**未激活**。

{{I1}}

要使用已订阅的插件，请勾选它的**激活**复选框。OrcaSlicer 会根据需要安装或加载该插件。

{{I2}}

激活完成后，插件状态会变为**已激活**。展开插件所在的行，可以看到可用的插件功能。

{{I3}}

## 更新云端插件

如果有更新的云端版本，插件详细信息中会显示**更新**按钮。

{{I4}}

单击**更新**并等待更新完成。

{{I5}}

更新后，已安装版本和最新版本应当一致。

{{I6}}
