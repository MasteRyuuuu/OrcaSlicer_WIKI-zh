# 管理插件

选择一个插件，即可在下方面板中查看它的信息。各选项卡显示的内容如下：

| 选项卡 | 显示内容 |
|---|---|
| **插件信息** | 来源、类型、作者、已安装版本和最新版本 |
| **描述** | 插件作者提供的信息 |
| **配置** | 插件各项功能的 JSON 配置或自定义配置 |
| **更新日志** | 版本历史（如果有提供） |
| **诊断** | 加载或错误信息 |

右键单击本地插件可以管理它。

{{I1}}

常用操作包括：

- **删除**移除本地插件，或云端插件的已安装副本。删除已订阅的云端插件不会取消订阅。
- **取消订阅**取消云端插件的订阅，并移除其已安装副本。
- **在文件夹中显示**打开插件在你电脑上的位置。
- **重新安装**从源文件再次安装插件。

如果你安装、更新或订阅了插件但列表还没有变化，请使用**刷新**。

## 插件状态

**状态**列会显示以下其中一种：

| 状态 | 含义 |
|---|---|
| **已激活** | 插件已加载，可以使用。 |
| **载入中** | 插件仍在安装或加载中。 |
| **未激活** | 插件已安装但未激活。勾选其**激活**复选框即可加载。 |
| **错误** | 插件无法加载，在错误修复之前一直被阻止。 |
| **RuntimeError** | 插件已加载，但其中某项功能报告了错误（例如，某个打印机连接的 ID 已被其他插件或内置连接占用）。插件仍保持激活，受影响的功能会被关闭。 |

**激活**复选框显示插件是否已加载。停用插件会清除它的错误。
打开**诊断**选项卡可以查看错误详情。

## 孤立插件和缺失插件

你不再订阅的云端插件，或在 OrcaCloud 上已不再提供的云端插件，会显示为**孤立**。它的本地副本仍然保持安装并且可以继续使用，但无法再从云端重新安装或更新。使用**删除**可以移除它。

如果 OrcaSlicer 发现某些已安装插件的文件已从你的电脑上删除，它会列出这些插件，并提供从 OrcaSlicer 中移除它们的选项。

## 权限

当插件试图访问 OrcaSlicer 默认允许范围以外的文件夹中的文件、连接网络或启动程序时，OrcaSlicer 会请求你的许可，并为该插件记住大部分答复。再次安装插件、使用**重新安装**或更新插件，都会清除已记住的权限，新版本需要重新请求。

禁用插件或其中某项功能，会把它从使用它的工作流程中移除。引用了未激活或缺失功能的预设会显示缺失插件的通知，在引用得到解决或相关设置被修改之前无法切片。
