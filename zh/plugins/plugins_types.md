# 插件类型

一个插件可以提供一项或多项功能。展开插件所在的行，可以看到它的插件功能。

{{I1}}

## 脚本

脚本插件在插件窗口中手动运行。

1. 打开**文件** > **插件**。
2. 展开该插件。
3. 找到脚本功能。
4. 单击**运行**按钮。

{{I2}}

## 切片流水线

{{M1}}
切片流水线插件在切片工作流程中选定的节点运行。它们可以检查或修改实时的切片图，或者在后处理步骤中编辑导出的 G-code。这项功能是实验性的，面向插件开发者和测试者。

启用后，插件的功能会出现在相应的插件设置或工作流程中。
`psGCodePostProcess` 步骤在传统的后处理脚本之后运行，接收的是工作中 G-code 的路径；几何处理步骤接收的则是当前的切片上下文。

> [!WARNING]
> 切片流水线插件可以改变生成的几何形状或 G-code。用于打印之前，请审查并测试来自你信任来源的插件。

## 页面

页面插件会在主窗口中添加自己的选项卡，位于 OrcaSlicer 内置选项卡之后。插件功能激活时选项卡出现，停用时消失。

如果激活了很多页面插件，可以在**偏好设置** > **常规** > **插件** > **可见插件页数**中设置并排显示多少个选项卡（1 到 10，默认 5）。其余页面会列在最后一个插件选项卡的下拉菜单中。

## 资源纹理

资源纹理插件以资源包的形式提供高度图图像。每个插件提供一个图像包，在应用中以包的名称显示。

这类插件只能以 wheel（`.whl`）形式安装，因为资源包除了代码之外还附带图像文件。

启用、禁用或卸载一个包会增加或移除它的纹理，而且无需重启即可生效。已经使用过某个包内纹理的项目仍然可以正常使用，因为项目中保存了图像的副本。

## 插件配置

选择一个插件，打开**配置**选项卡，然后选择它的一项功能。编辑 JSON 配置并单击**保存**。**恢复默认**会删除该功能已保存的配置，改用插件的默认配置。

当某个预设使用了插件功能时，也可以针对该预设覆盖其配置。保存预设时，覆盖配置会随预设一起保存；否则该功能使用其全局配置。

## 快捷面板

[快捷面板]({{L1}})可以快速访问已安装的插件。

## 打印机连接

打印机连接插件增加与打印机通信的功能。打印机代理工作流程仍在开发中。

对于非 Bambu Lab 的打印机，只有在启用**偏好设置** > **开发者** > **实验性功能** > **使用打印机代理替代打印主机**时，OrcaSlicer 才会通过打印机连接插件发送打印任务。该选项默认关闭，因此默认使用传统的打印主机上传。

每个打印机连接都有一个 ID。如果某个插件的打印机连接使用的 ID 已被其他插件或内置连接占用，OrcaSlicer 会显示警告、关闭该功能，并把插件标记为 **RuntimeError** 状态。参见[管理插件]({{L2}})。

如果插件有自己的设置说明，请查看插件窗口中的**描述**或**诊断**选项卡。
