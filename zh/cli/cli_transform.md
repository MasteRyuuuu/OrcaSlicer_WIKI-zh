# 命令行变换

变换选项在切片之前改变加载模型的几何形状或位置。通用的标志语法请参见[命令行模式]({{L1}})。

> [!IMPORTANT]
> 变换标志按它们在命令行中出现的顺序应用，而不是按本页列出的顺序。`--rotate 90 --scale 2` 先旋转再缩放；`--scale 2 --rotate 90` 先缩放再旋转。对其中大多数选项来说，两种顺序的最终结果相同，但同时组合多个选项时，最好有意识地安排顺序。

{{T1}}

## 摆放

| 标志 | 输入 | 说明 | 备注 |
| --- | --- | --- | --- |
| `--arrange` | `option`（整数） | 在盘上摆放对象：`0` = 禁用，`1` = 强制启用，其他任何值 = 自动。其底层行为参见[自动摆放]({{L2}})。 | |
| `--ensure-on-bed` | 布尔值 | 把部分位于热床以下的对象抬升到热床上。 | 默认禁用。 |
| `--orient` | `option`（整数） | 自动调整对象朝向：`0` = 禁用，`1` = 强制启用，其他任何值 = 自动。参见[自动朝向]({{L3}})。 | |

## 几何

| 标志 | 输入 | 说明 | 备注 |
| --- | --- | --- | --- |
| `--convert-unit` | 布尔值 | 检测以米或英寸保存的模型，并将其转换为毫米。 | |
| `--repair` | 布尔值 | 像[修复模型]({{L4}})那样修复加载模型的每个零件：闭合孔洞和裂缝、让网格朝外，并去除局部自相交。绘制数据会保留。 | 默认禁用。修复后仍无法成为实体的零件会保持原样，并在日志中给出警告。 |
| `--rotate` | 角度（浮点数） | 把每个加载的对象绕 Z 轴旋转。参见[旋转]({{L5}})。 | |
| `--rotate-x` | 角度（浮点数） | 把每个加载的对象绕 X 轴旋转。 | |
| `--rotate-y` | 角度（浮点数） | 把每个加载的对象绕 Y 轴旋转。 | |
| `--scale` | `factor`（浮点数） | 按此系数缩放每个加载的对象。参见[缩放]({{L6}})。 | 必须大于 `0`。 |

## 对象处理

| 标志 | 输入 | 说明 | 备注 |
| --- | --- | --- | --- |
| `--repetitions` | `count`（整数） | 在盘上把整个模型复制这么多次。 | 要求 [`--slice`]({{L7}}) 指定单个盘（不能是 `0`/所有盘）。不能超过盘的数量。 |
| `--assemble` | 布尔值 | 把所有加载的模型合并为一个盘上的单个对象，使后续操作作用于整体。 | 不能与 [`--clone-objects`]({{L8}}) 同时使用。 |
