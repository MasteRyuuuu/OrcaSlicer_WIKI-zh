# 命令行操作

操作选项告诉 OrcaSlicer 要对加载的模型*做*什么——导出、切片或检查。通用的标志语法请参见[命令行模式]({{L1}})。

{{T1}}

## 导出

| 标志 | 输入 | 说明 | 备注 |
| --- | --- | --- | --- |
| `--export-3mf` | `filename.3mf` | 把项目导出为 3MF 文件。 | 默认文件名：`output.3mf`。 |
| `--export-slicedata` | `slicing_data_directory` | 把切片数据（切片结果缓存）导出到一个文件夹。 | 不能与 `--load-slicedata` 同时使用。 |
| `--load-slicedata` | `slicing_data_directory` | 从目录加载之前缓存的切片数据，而不重新切片。 | 不能与 `--export-slicedata` 或 [`--repetitions`]({{L2}}) 同时使用。 |
| `--export-stl` | 布尔值 | 把模型导出为单个 STL。 | |
| `--export-stls` | `stl_path` | 把模型导出为多个 STL（每个对象一个）到一个目录。 | |
| `--min-save` | 布尔值 | 以最小体积导出 3MF（去除打印不需要的额外数据）。 | |
| `--export-settings` | `settings.json` | 把当前生效的工艺/打印机/耗材丝设置导出为 JSON 文件。 | 默认文件名：`output.json`。 |

## 切片

| 标志 | 输入 | 说明 | 备注 |
| --- | --- | --- | --- |
| `--slice` | `option`（整数） | 对盘进行切片：`0` = 所有盘，`i` = 第 `i` 个盘，其他任何值均无效。 | |
| `--mtcpp` | `count` | 切片时每个盘允许的最大三角面数量。 | 默认：`1000000`。 |
| `--mstpp` | `time`（秒） | 每个盘允许的最长切片时间。 | 默认：`300`。 |
| `--no-check` | 布尔值 | 跳过有效性检查，例如 G-code 路径冲突检测。 | |
| `--normative-check` | 布尔值 | 运行规范性（规格）检查。 | 默认：开启。 |

## 模型信息

| 标志 | 输入 | 说明 | 备注 |
| --- | --- | --- | --- |
| `--info` | 布尔值 | 把加载模型的信息（对象/实例数量、尺寸等）输出到标准输出。 | 针对未修复的模型运行。 |

## 其他操作

| 标志 | 输入 | 说明 | 备注 |
| --- | --- | --- | --- |
| `--help` / `-h` | 布尔值 | 输出命令行用法帮助。 | |
| `--uptodate` | 布尔值 | 把加载的 3MF 中嵌入的配置值更新为当前 OrcaSlicer 版本的默认值/结构。 | |
| `--load-defaultfila` | 布尔值 | 对于没有显式加载耗材丝的对象，使用第一种耗材丝作为其默认耗材丝。 | |
| `--pipe` | `pipename` | 把切片进度更新发送到命名管道，用于与外部工具集成。 | |
