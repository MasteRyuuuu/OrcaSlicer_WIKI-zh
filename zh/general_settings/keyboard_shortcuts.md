# 快捷键

本页列出应用程序中可用的键盘快捷键，以及如何修改它们。

{{T1}}

快捷键按其作用的视图分组，与应用内列表的分组方式相同。同一个按键在不同视图中可能有不同含义：`C` 在"准备"中是切割工具，在"预览"中是 G-code 窗口，在绘制时则是圆形工具。全局快捷键是例外——它们在任何地方都有效，因此其他功能都不能使用这些按键。

## 自定义快捷键

本页的每个按键都是默认设置，几乎全部都可以修改。可以从以下位置打开编辑器：

- **帮助 → 快捷键**
- **偏好设置 → 控制 → 快捷键 → 编辑…**
- 在 3D 视图获得焦点时按 `?`，会打开列表中该视图对应的页面。

要重新分配快捷键，选中它所在的行，然后按下新的组合键。如果已有其他快捷键使用了这个组合，对话框会列出它们，并且只有在你确认后才会解除它们的绑定。**重置**会恢复默认设置；如果该默认按键此时已被其他功能占用，也会询问同样的问题。快捷键也可以不绑定任何按键。

只有你自己的更改会被保存，所以如果以后的版本改进了某个默认快捷键，你仍然能用上。

编辑器会执行以下几条规则：

- **全局**快捷键必须包含 `Ctrl` 或 `Alt`，或者使用不会输入字符的按键，例如功能键。如果把一个单独的字母保留为全局快捷键，它会在每个文本框中被吞掉。`Space` 是唯一的例外——它用于打开[快捷面板]({{L1}})，并且在文本框、按钮或组合框获得焦点时不起作用。
- 在有步长的按键上，`Shift` 和 `Ctrl` 被保留为**步长修饰键**：所选对象以 1 mm 步长移动和沿相机视角移动，以及滑动条 5 倍速移动。不能在这类按键上再叠加分配它们。
- 有些行是固定的，不能重新分配：鼠标按键、`Esc`、选择耗材丝的数字键，以及上面提到的步长修饰键。
- 按键按物理位置匹配，而不是按键帽上印的字母匹配，所以在 `Q` 位置不同的键盘布局下，仍然会触发同一个快捷键。小键盘数字等同于主键盘区的数字。标点符号指的是你的键盘布局所输入的字符，无论它位于哪个键上。

列表中的鼠标拖动行不是按键。它们显示的是拖动时每个鼠标按键的作用，在**偏好设置 → 控制**中设置：`鼠标左键拖动`（默认为旋转）、`鼠标中键拖动`和`鼠标右键拖动`（默认都是平移），每一项都可以设为无、平移或旋转。

| `Ctrl + 0` | 视图 - 默认视图 |
| `Ctrl + 1` | 视图 - 俯视图 |
| `Ctrl + 2` | 视图 - 仰视图 |
| `Ctrl + 3` | 视图 - 前视图 |

| `Ctrl + 6` | 视图 - 右视图 |

## 设计

[设计选项卡]({{L4}})的快捷键；在偏好设置中启用 CAD 功能后才会显示该选项卡。这个选项卡有两套按键映射：打开草图时，单个字母驱动草图工具；没有打开草图时，`Shift` 加字母驱动建模工具。两套映射的完整列表见[设计快捷键]({{L5}})；下面列出的是作用于视图和文档的按键。设计选项卡的按键是固定的：它们不属于可分配的快捷键集合，因此不会出现在快捷键编辑器中。

| 按键 | 操作 |
| --- | --- |
| `Home` | 等轴测视图，并缩放到适合模型 |
| `P` | 显示或隐藏原点平面 |
| `A` | 显示或隐藏世界坐标轴 |
| `X` | 开启或关闭剖面视图 |
| `Page Up` / `Page Down` | 剖面视图开启时，移动剖切平面 |
| `F` | 剖面视图开启时翻转剖面，否则把选中的面平放到热床上 |
| `Ctrl + Shift + B` | 显示或隐藏打印机热床 |
| `Ctrl + Shift + P` | 提交到盘 |
| `Menu` / `Shift + F10` | 打开当前所选对象的操作菜单 |
| `F2` | 重命名所选特征 |
| `Esc` | 清除选择 |
