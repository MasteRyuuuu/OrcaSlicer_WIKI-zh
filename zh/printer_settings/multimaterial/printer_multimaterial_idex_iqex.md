# IDEX/IQEX 配置

这些设置描述带有可同时打印的独立滑车的打印机。OrcaSlicer 为 T0 切片零件，再由打印机固件在其他滑车上重复打印。IDEX（独立双挤出机）打印机有两个滑车，可以并排装在一个龙门上，也可以前后各装在一个龙门上；IQEX（独立四挤出机）打印机有两个龙门，每个龙门两个滑车。其他布局（例如一个龙门上装三个或四个滑车）也使用相同的设置。

这些设置位于 **打印机设置 → 多材料 → IDEX/IQEX 配置**，设置模式为 **高级** 或更高时才会显示。在启用 [IDEX/IQEX 打印机]({{L1}})之前，它下面的设置（"切片前警告"除外）都是灰色的，[模式]({{L2}})表格也会被隐藏。

{{I1}}

[IDEX/IQEX 并行打印]({{L3}})指南说明了这些设置如何协同工作，以及如何为每个盘选择模式。

{{T1}}

## IDEX/IQEX 打印机

{{M1}}
标记这台打印机具有可以并行打印的独立滑车。之后每个盘都会多出一个用于选择并行模式的图标，本页其他设置也变为可编辑。

对于工具头一次只能用一个的打印机（包括普通的双挤出机和换头式机器），请保持禁用。

## 固件管理区域

{{M2}}
在并行模式下，以 T0 区域的中心作为 X0 Y0 来写出 G-code，由固件把每个滑车从那里移到各自的区域。主模式不受影响。

对于从 T0 的打印位置重复 T0 动作的固件（例如 Klipper 的复制和镜像模式），请保持禁用。

启用后，盘上不绘制幽灵副本，预览显示平移后的 G-code。

## 龙门数量

{{M3}}
独立 Y 龙门的数量：单龙门（如经典 IDEX）为 `1`；前后两个龙门（如 IQEX 或双龙门 IDEX）为 `2`。使用两个龙门的模式会把热床分为前排和后排两行区域。

## 每个龙门的工具头数

{{M4}}
每个龙门上沿 X 方向并排的独立滑车数量。经典 IDEX 为 `2`。

工具头先在 T0 所在的龙门上编号：在 IQEX 上，T0 和 T1 共用一个龙门，T2 和 T3 在另一个龙门上，T2 正对着 T0。

## 工具头 0 位置

{{M5}}
T0 所在的热床角落。T0 是主工具头：它打印切片得到的零件，其他滑车对其进行复制或镜像。这个设置告诉 OrcaSlicer 哪个区域属于 T0，其他工具头的区域由此推出。

在单龙门打印机上，只需要区分左右；在双龙门打印机上，T0 可以在四个角中的任意一个。前指 Y 较小（靠近你）的一侧，后指 Y 较大的一侧。

## 喷嘴避让距离 X

{{M6}}
从喷嘴中心到其工具头（包括风扇和风道）朝向相邻滑车一侧最外点的距离，单位 mm。请在打印机上实测。

在 T0 区域与同一龙门上某个镜像区域的分界线旁，OrcaSlicer 会在 T0 区域内画出一条这么宽的条带，因为镜像的滑车会相向移动。只要有零件或擦拭塔与这条条带重叠，该盘就无法切片。复制滑车与 T0 同向移动，不会相撞，所以没有条带。

这一个值同时适用于分界线两侧的滑车。镜像对称的工具头，以及喷嘴在 X 方向居中的工具头，两侧测得的值相同。如果两侧不同（例如工具头相同、但喷嘴在 X 方向偏离中心），请填较大的那个值。

{{I2}}

## 喷嘴避让距离 Y

{{M7}}
从喷嘴中心到其工具头朝向另一个龙门一侧最外点的距离，单位 mm。在双龙门打印机上，它设定前后两排分界线旁条带的宽度，只有当分界线对面的滑车为镜像时才会绘制。

与 X 一样，如果两侧不同（例如工具头相同、但喷嘴在 Y 方向偏离中心），请填较大的那个值。

{{I3}}

## 安全边距

{{M8}}
可选的额外区域（单位 mm），画在 T0 区域内每条避让条带的旁边，提醒你让零件远离它。与避让条带不同，放在这个区域内的零件仍然可以切片。它只会出现在有避让条带的地方。

## 切片前警告

在并行模式下用 **切片单盘** 或 **切片所有盘** 对某个盘切片之前，如果另一个激活滑车的耗材与 T0 的热床温度相差超过 5 °C，或者耗材类型不同，就会发出警告。热床温度由 T0 控制，所以其他滑车只能按 T0 设定的温度打印。

这个警告可以在其自身的对话框中关闭，而这个设置可以重新开启它。它是整个应用的偏好设置，而不属于打印机预设，所以会同时作用于所有 IDEX/IQEX 打印机，也永远不会把预设标记为已修改。

## 可视化主题

{{M9}}
热床上区域、条带和边距所用的颜色。如果标准颜色难以分辨，可以选择对色盲友好的主题：

- **标准**
- **绿色盲 / 红色盲（红绿）**
- **蓝色盲（蓝黄）**
- **高对比度**

## 模式

这一组设置底部的 **模式** 表格定义每个盘可用的并行模式。每一行是一种模式：一个名称、每个工具头的角色，以及通知固件的 G-code。

第一行是 **主（Primary）**，即普通模式：任何工具头都可以打印，但一次只用一个。它不能被删除，它的 G-code 在主模式打印时也会写出。用 **添加模式** 添加一行，用模式名称下方的删除按钮删除它。设为被删除模式的盘会回到主模式。

### 模式名称

在盘的模式菜单中显示的名称。盘是按名称保存模式的，所以重命名或删除已保存项目所用的模式，会让该项目的盘按主模式打印，并在切片时给出警告。

### 工具头角色

单击某个工具头的方块可以循环切换它的角色。T0 总是打印切片得到的零件，所以它的方块固定为"主"。主模式那一行的方块不能更改。

- **未激活**（灰色）：该工具头在这个模式下不打印。
- **复制**：在自己的区域里打印同样的零件，运动方式与 T0 相同。
- **镜像**：在自己的区域里打印零件的镜像，以它与 T0 区域的分界线为对称轴：与 T0 同一龙门上的沿 X 镜像，另一龙门上的沿 Y 镜像。
- **Span**：在双龙门打印机上，让 T0 所在龙门上的某个工具头成为多色搭档，在 T0 的区域里打印它自己的耗材，同时由另一个龙门复制或镜像打印结果。只在 T0 所在的龙门上提供。

### 模式 G-code

OrcaSlicer 为这个模式写出的 G-code，位于打印机起始 G-code 之前。它在打印机回原点之前运行，所以通常只记录模式，由起始 G-code 在回原点之后把打印机切换到该模式；指南中的[固件]({{L4}})一节解释了原因。它会经过占位符解析器处理，所以可以使用变量。变量 [`imex_mode`、`imex_mode_index` 和 `imex_mode_gcode`]({{L5}}) 也会把当前模式提供给打印机起始 G-code。`imex_mode` 保存模式的名称，主模式下写作 `primary`。
