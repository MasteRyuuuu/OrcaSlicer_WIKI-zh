# 冷却风扇

机器冷却风扇设置。

{{T1}}

## 风扇响应时间

{{M1}}
让风扇比其目标启动时间提前这么多秒启动（可以使用小数秒）。这个时间估算假定加速度无限大，并且只考虑 G1 和 G0 移动（不支持圆弧拟合）。
它不会移动自定义 G-code 中的风扇命令（这些命令相当于一道"屏障"）。
如果启用了"仅自定义起始 G-code"，它不会把风扇命令移入起始 G-code。
设为 0 可停用。

### 仅悬垂

只在悬垂冷却时考虑这个提前量。

## 风扇全速启动时间

{{M2}}
在降到目标速度之前，先输出一条最大风扇速度命令并持续这么多秒，以"踢启"冷却风扇。
这适用于低 PWM/功率不足以让风扇从静止开始转动的风扇，或者想让风扇更快达到转速的情况。
设为 0 可停用。

## 最小非零部件冷却风扇速度

{{M3}}
有些部件冷却风扇在 PWM 占空比低于某个值时无法启动。
设为大于 0 的值后，任何非零的部件冷却风扇命令都会被提高到至少这个百分比，以确保风扇可靠启动。  
风扇命令为 0（关闭风扇）时始终严格执行。  
这个下限在其他所有风扇计算（首层渐变、层时间插值、悬垂/桥接/支撑面/熨烫覆盖）之后才施加，所以缩放仍在 [这个值, 100%] 的范围内进行。  
如果你的固件已经在某个阈值以下关闭风扇（例如 Klipper 的 [fan] off_below: 0.10 会在命令占空比低于 10% 时关闭风扇），这个选项最好与固件阈值设为相同的值。  
让两者一致（例如 Klipper 中 off_below: 0.10，这里设 10%），可以保证切片软件永远不会输出被固件悄悄丢弃的非零值，风扇也永远不会收到低于你确认它能转起来的值。  
设为 0 可停用。
