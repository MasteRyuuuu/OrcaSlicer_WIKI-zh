# 机器坐标系变换

{{I1}}

这些设置为传送带打印机把 OrcaSlicer 的坐标转换为机器坐标。它们位于 **打印机设置 → 基本信息 → 机器坐标系变换**，启用[传送带打印]({{L1}})后才会显示。重映射各行只在 **开发者** 模式下显示。

变换按以下顺序进行：

1. [G-code 轴重映射]({{L2}})决定每个机器轴对应哪个切片轴。
2. [机器坐标系倾斜]({{L3}})补偿龙门与传送带不垂直的问题。

这些设置在打印机配置中设定，以匹配机器的运动学结构。[传送带打印]({{L4}})指南解释了它们在切片过程中的作用。

> [!CAUTION]
> 错误的数值可能把工具头送到意料之外的位置，甚至可能超出机器的行程极限。请在预览的视图菜单中用 **显示原始 G-code（仅传送带）** 检查结果（见[预览]({{L5}})），并在打印机旁盯着第一次打印。

{{T1}}

## 轴重映射的工作原理

轴重映射有三个字段：**X**、**Y** 和 **Z**，每个对应一个输出轴。每个字段选择一个输入轴，并定义其坐标如何映射到输出。三个字段组合起来，可以在不改变距离的前提下交换、翻转和镜像各轴。

### 重映射取值

| 取值 | 所选输入轴上坐标 `v` 的结果 |
| --- | --- |
| **+X**、**+Y**、**+Z** | `v`：坐标被原样复制。 |
| **-X**、**-Y**、**-Z** | `-v`：坐标取反，即该轴绕原点翻转。 |
| **反转 X**、**反转 Y**、**反转 Z** | `max - v`：该轴在打印体积内镜像，0 变为 `max`，`max` 变为 0。 |

对于"反转"取值，`max` 是所选输入轴的最大坐标：X 或 Y 为[可打印区域]({{L6}})中的最大 X 或 Y 坐标，Z 则为[可打印高度]({{L7}})。

三个字段都保持 **+X**、**+Y**、**+Z** 时，坐标保持不变。

### 示例：传送带配置

OrcaSlicer 自带的传送带配置使用以下 [G-code 轴重映射]({{L8}})：

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| **X** | 反转 X | 机器 X 横跨传送带，且做了镜像：`X = 宽度 - x`。 |
| **Y** | +Z | 机器 Y（龙门轴）取高出传送带的高度。 |
| **Z** | +Y | 机器 Z（传送带轴）取沿传送带的位置。 |

因此，在 350 mm 宽的传送带上，准备视图中位于 `x = 20`、`y = 100`、`z = 5` 的点会被重映射为 `X = 330`、`Y = 5`、`Z = 100`。然后再对这些坐标施加[机器坐标系倾斜]({{L9}})。

### 重映射在哪里施加

重映射作用于切片后的工具路径，所以它只改变写出每段移动时所用的轴字母和坐标值。模型本身只在切片前按[传送带倾斜]({{L10}})旋转，而这个旋转在重映射之前会被撤销，所以重映射接收到的点是在准备视图中摆放的模型坐标系下的点。

```mermaid
flowchart LR
    A[模型] --> B[传送带倾斜旋转]
    B --> C[切片]
    C --> D[反向变换]
    D --> E[G-code 轴重映射]
    E --> F[机器坐标系倾斜]
    F --> G[G-code]
```

### 需要注意的地方

- **每个输入轴恰好使用一次。** OrcaSlicer 不会检查这一点。把同一个输入轴分配给两个输出（例如 X 和 Y 字段都设为 **+X**），会丢掉一个轴，打印件会被压扁。
- **自定义 G-code 不会被重映射。** 起始、结束、换层以及其他[机器 G-code]({{L11}})会原样写入文件，所以它们必须本来就是机器坐标。
- 启用重映射时，**每段移动都会写出 X、Y 和 Z**，因为任何切片轴都可能映射到任何机器轴。
- **圆弧移动受限。** 只有 X 和 Y 保持为 **+X** 和 **+Y** 时才会写出 G2/G3 圆弧。传送带打印机上会禁用[圆弧拟合]({{L12}})。
- **重映射保存在打印机配置中。** 禁用传送带打印时这些字段会被隐藏，但已配置的重映射仍然有效。

## G-code 轴重映射

{{M1}}
在导出的 G-code 中，选择每个机器轴对应哪个切片轴。重映射在切片之后、生成 G-code 时施加，不改变工具路径。

**G-code 重映射 X**、**Y** 和 **Z** 各行代表机器轴。各取值的说明见[轴重映射的工作原理]({{L13}})。

只有当设置[模式]({{L14}})为 **开发者** 时才会显示这些字段。

> [!NOTE]
> 随后的[机器坐标系倾斜]({{L15}})要求使用传送带配置所采用的轴映射：龙门轴上是高出传送带的高度，机器 Z 上是沿传送带的位置。

## 机器坐标系倾斜

{{M2}}
在传送带打印机上，龙门与传送带并不垂直。因此龙门每移动一毫米，喷嘴升高不到一毫米，同时还会沿传送带移动。机器坐标系倾斜会补偿这两种效应，使打印出的零件与模型一致。

{{I2}}

对于高出传送带 `h`、沿传送带位置为 `y` 的点，在龙门倾斜角为 `α` 时：

- 龙门必须移动 `h / sin α` 才能到达这个高度。
- 经过该点的层与传送带的交点要再往前 `h · cot α`，所以传送带位置为 `y + h · cot α`。

使用[传送带配置的重映射]({{L16}})、且[传送带倾斜]({{L17}})绕 X 轴时，重映射后的坐标按如下方式转换为机器坐标：

$$
\begin{bmatrix} X_{machine} \\ Y_{machine} \\ Z_{machine} \end{bmatrix} =
\begin{bmatrix} X \\ \dfrac{Y}{\sin\alpha} \\ Z + Y\cot\alpha \end{bmatrix}
$$

如果传送带倾斜绕 Y 轴，同样的修正改为作用在 X 而不是 Y 上：X 除以 `sin α`，Z 变为 `Z - X · cot α`。

绕 X 轴倾斜 45° 时，可以简化为：龙门为 `Y · 1.414`，传送带为 `Z + Y`。90° 时龙门与传送带垂直，坐标保持不变。

默认情况下，这个角度就是[传送带倾斜角度]({{L18}})，所以同一个值同时控制切片时的旋转和这里的修正。当[倾斜轴]({{L19}})为 **Z** 或 **无** 时不进行修正。

### 解耦机器坐标系倾角

允许机器坐标系修正使用与传送带倾斜角度不同的另一个角度。

只有当龙门的实际物理倾角与切片角度不同时才启用这个选项，例如在 45° 的机器上以 30° 切片。

> [!WARNING]
> 以不同于龙门倾角的角度切片，会改变喷嘴和热端与之前已打印层之间的距离。打印前请检查间隙。

### 机器坐标系倾斜角度

启用[解耦机器坐标系倾角]({{L20}})时，用于机器坐标系修正的角度，单位为度。未启用时忽略。
