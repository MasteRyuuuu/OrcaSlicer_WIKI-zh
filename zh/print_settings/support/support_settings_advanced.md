# 支撑高级设置

{{T1}}

## Z 距离

{{M1}}
支撑与物体之间的 Z 向间隙：**顶部 Z 距离**是支撑顶部与其上方悬垂之间的间隙，**底部 Z 距离**是物体与立在它上面的支撑之间的间隙。除非启用了[支撑独立层高]({{L1}})，否则两者都会被取整为层高的整数倍。

顶部 Z 距离为 `0` 是为可溶性支撑准备的。这种情况下，如果有底部支撑面层，底部 Z 距离也会被忽略，支撑与物体直接接触打印。

## 支撑墙层数

{{M2}}
这个设置指定支撑墙的圈数，范围为 0 到 2。0 表示自动。

## 支撑主体图案

{{M3}}
支撑主体的线条图案。

`默认` 取决于支撑类型：普通支撑使用 `直线`，树状支撑则保持 `空心`，只打印分枝的墙。使用[混合树]({{L2}})样式时，`默认` 会用 `直线` 填充按普通支撑打印的部分，而分枝保持空心；选择 `直线` 则连分枝也会被填充。

### 主体图案线距

{{M4}}
支撑线之间的间距。

## 图案角度

{{M5}}
用这个设置在水平面内旋转支撑图案。

## 支撑面层数

{{M6}}
支撑面的层数。

你设定的数值就是致密支撑面的总厚度，按打印层数计算，包括朝向模型的那一层。设为 `1` 就得到一层致密层；设为 `3` 就得到三层。层数越多，被支撑的表面越平整、支撑越好，但打印时间更长，也更难剥离。

顶部和底部支撑面分别设置：

- **顶部支撑面层数**（`support_interface_top_layers`）是打印在悬垂下方、位于 [Z 距离]({{L3}})间隙之下的那些层。它们决定被支撑表面的效果。
- **底部支撑面层数**（`support_interface_bottom_layers`）是在支撑落在模型上的地方打印的那些层，用来保护该表面不受支撑主体的影响。`和顶部相同` 会沿用顶部的值。你也可以单独使用底部支撑面，把顶部支撑面层数设为 `0`。

两者都设为 `0` 时就完全没有支撑面：支撑从头到尾都用[支撑主体图案]({{L4}})打印，这样最快、最容易拆除，但悬垂表面最粗糙。

> [!TIP]
> 当支撑面单独指定了耗材时，这个数值还决定了两种材料之间如何分配各层。参见[支撑面耗材的过渡]({{L5}})。

## 支撑面图案

{{M7}}
支撑面使用的图案。

每个选项对支撑面线条的排布方式不同，而且都以[图案角度]({{L6}})为基准测量，所以旋转图案角度时，支撑面也会随之旋转。普通支撑和树状支撑都遵循同样的规则。

| 选项 | 效果 |
| --- | --- |
| `默认` | 与图案角度成 90° 横穿支撑的直线。当支撑面接触模型时（可溶性支撑通常如此），改用同心环路。 |
| `直线` | 与图案角度成 90° 的直线。使用[紧贴]({{L7}})样式时会再额外旋转 45°。 |
| `同心` | 沿支撑面轮廓的环路，可以整块剥离，并且不会在表面留下线头。 |
| `螺旋内缩` | 与 `同心` 类似，但各圈环路连成一条连续的[螺旋]({{L8}})，喷嘴从一圈直接走到下一圈，不必停顿。 |
| `交叠的直线` | 每一层先向一侧、再向另一侧摆动 45° 的直线，使各层交叉而不是叠在一起。这能把支撑面连成一体，使它在悬垂下方更坚挺。 |
| `网格` | 每一层都是交叉成网格的直线：一组沿着图案角度，与下面的[支撑主体图案]({{L9}})对齐，另一组与之成 90°。 |

如果[支撑面线距]({{L10}})宽到支撑面不再是实心的，`默认` 和 `直线` 会改用支撑主体图案，让稀疏的线条仍能相互锚定。

## 支撑面线距

{{M8}}
支撑面线条的间距。零表示实心支撑面。

顶部（`support_interface_spacing`）和底部（`support_bottom_interface_spacing`）的值分别设置，互不影响，所以即使你关闭了顶部支撑面，底部支撑面也会保持你给它设定的间距。

启用[支撑熨烫]({{L11}})时，顶部支撑面总是以实心打印，顶部的值会被忽略。

## 普通支撑拓展

{{M9}}
扩大（+）或缩小（-）普通支撑的水平范围。

## 支撑/物体 XY 距离

{{M10}}
物体与其支撑之间的 XY 间距。

## 支撑/物体首层间隙

{{M11}}
首层上物体与其支撑之间的 XY 间距。

## 不支撑桥接

{{M12}}
不为桥接区域生成支撑，否则支撑会变得非常大。只要桥接不是很长，通常无需支撑就能直接打印。

这个选项只对普通支撑显示。树状支撑改用[最大桥接长度]({{L12}})。

## 最大桥接长度

{{M13}}
树状支撑保持不支撑的最长桥接。对于包括有机树在内的所有树状样式，它取代了[不支撑桥接]({{L13}})。两端都有锚定、长度不超过该值的桥接不加支撑直接打印，更长的桥接则沿其全长加支撑。`0` 表示支撑所有桥接，很大的值则表示所有桥接都不加支撑。

使用苗条树、粗壮树和混合树样式时，放在悬垂内部的分枝尖端之间的间距也至少为这个长度的一半，所以大于两倍[分枝距离]({{L14}})的值会让它们分布得更开。

## 支撑独立层高

{{M14}}
支撑层使用独立于物体层的层高。这样可以自定义 Z 间隙，并节省打印时间。打印擦拭塔时会忽略这个选项，有机树支撑样式也不能使用它。

开启后改变的是支撑层的高度，而不是层数：你仍会得到所设定的确切[支撑面层数]({{L15}})，`苗条树`、`粗壮树` 和 `混合树` 样式也是如此。
