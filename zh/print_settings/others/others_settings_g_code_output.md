# G-code 输出

这些设置控制 G-code 如何生成和格式化。它们影响可读性、文件大小、打印行为，以及与固件和后处理工具的兼容性。

{{T1}}

## 减小填充回抽

{{M1}}
启用后，切片软件会对完全位于填充区域内部的空驶跳过回抽。这样能减少回抽次数，对复杂模型可以加快打印，但填充内部的渗料或拉丝可能会增加。切片时间也可能略有增加。

每次回抽都会增加一些不打印任何东西的动作，而跳过回抽的空驶会把这些动作全部省掉，只保留空驶本身：

- [回抽]({{L1}})会在空驶之前以[回抽速度]({{L2}})把耗材往回拉，而[回填]({{L3}})会在下一条线开始之前把它推回去（再加上任何[额外回填长度]({{L4}})）。在默认的 0.8 mm、30 mm/s 下，这两步各需约 27 ms。
- 启用[回抽时擦拭]({{L5}})时，喷嘴还会在回抽的同时沿最后一条线往回移动[擦拭距离]({{L6}})。
- 使用 [Z 抬升]({{L7}})时，喷嘴会在空驶前抬起、空驶后降下，这是在 Z 轴上进行的，而大多数打印机的 Z 轴比 X、Y 轴慢得多。

每次空驶几十毫秒，在大型打印件成千上万次的填充空驶中可以累积到好几分钟。

短于[空驶距离阈值]({{L8}})的空驶无论是否启用这个选项都不会回抽。末端相邻的填充线会被连成一条路径（见[填充锚线]({{L9}})），所以它们之间没有需要回抽的空驶。

当内部的外观质量不重要、并且你希望减少回抽次数时，**推荐**启用。

## 标注行号

{{M2}}
给每行 G-code 加上顺序行号前缀（N1、N2……）。适用于调试，或需要带编号 G-code 的工具。

## 注释 G-code

{{M3}}
为 G-code 的行和代码块添加描述性注释，让文件更易读、更方便调试。  
注释模式会生成大得多的文件，在某些打印机上可能拖慢从 SD 卡打印的速度。

## 高精度 G-code

{{M4}}

X、Y、Z、I 和 J 坐标写为 4 位小数而不是 3 位，E 写为 6 位而不是 5 位，以减小 G-code 中的舍入误差。进给速度保留 3 位小数。  
使用[相对 E 距离]({{L10}})时，每段移动的舍入误差还会累计到下一段中，这样长度差不多的短移动就不会全都朝同一个方向舍入流量。

这可能有助于在使用小喷嘴（例如 0.2 mm）和薄层（例如 0.08 mm 或更薄）时稳定挤出，因为这时每段移动挤出的材料都很少，舍入误差的影响最大。效果在很大程度上取决于其余设置调得好不好，除非耗材和打印配置都已经过良好的[校准]({{L11}})，否则可能很难察觉。

- **支撑** 打印后会被拆掉，所以保持标准精度。支撑熨烫则保留更高的精度，因为它抹平的是物体打印在其上的表面。
- **文件大小：** G-code 会增大约 10%，这可能拖慢解析 G-code 较慢的打印机。
- **关闭：** G-code 与这个选项出现之前完全相同。

## 标注模型

{{M5}}
插入注释，标明每段移动属于哪个物体（物体索引或名称）。这对 OctoPrint 的 Cancel Object 插件等集成，以及人工查看 G-code 都很有用。

## 对象排除

{{M6}}
在 G-code 中添加定义每个物体并标记其起止位置的命令，让打印机固件可以在打印过程中跳过（取消）单个物体：Klipper 使用 `EXCLUDE_OBJECT_DEFINE`、`EXCLUDE_OBJECT_START` 和 `EXCLUDE_OBJECT_END`，Marlin 和 RepRapFirmware 使用 `M486`。

### 轮廓线公差

{{M7}}

控制用 Douglas-Peucker 算法简化的对象排除轮廓的精度。这个设置只适用于 **Klipper** 固件（`EXCLUDE_OBJECT_DEFINE` 行），因为 Marlin 和 RepRapFirmware 使用不带多边形定义的 `M486` 命令。

* **默认：** `0.1 mm`。
* **何时调整：** 如果打印机的 CPU 能力有限，而你又打印满满一盘、物体很多，非常精细的轮廓会生成非常大的数组。处理这些行或运行遍历它们的宏（如 KAMP 自适应网床）可能导致 Klipper 触发 `Timer too close` 错误。
* **建议：** 把这个值提高到 `0.2 mm` - `0.4 mm` 可以显著减少点的总数、避免打印机超时，而对轮廓精度的影响微乎其微。设为 `0` 会保留凸包的每一个点。
