# 速度高级设置——平滑挤出率

{{M1}}
平滑挤出率（Extrusion Rate Smoothing，ERS；PrusaSlicer 中叫压力均衡器 pressure equalizer）的目标是**把挤出体积的变化率限制在用户设定的阈值（即 ERS 值）以下**。  
它旨在帮助打印机固件内部的运动规划器和压力提前达到所需的喷嘴流量，减少与理想流量之间的偏差。

它的做法是减轻挤出系统所承受的冲击，同时减小压力提前平滑时间（smooth time）造成的、与理想挤出流量之间的绝对偏差。

在高加速度、大流量打印时，这项功能尤其有用，因为这时偏差更大。

> [!NOTE]
> 设为 0 会禁用平滑挤出率。任何大于 0 的值都会关闭[圆弧拟合]({{L1}})，并在平滑开启期间锁定该选项。

## 原理

启用这项功能后，在悬垂、悬垂墙等会导致挤出流量需求突变的特征之前和之后，会先降速再提速，形成一个小小的**速度"坡道"**。

具体做法是把打印的线段拆成与 ERS 分段长度成比例的若干小"块"，并降低这些小段的打印速度，使**所要求的挤出体积流量变化小于或等于 ERS 阈值**。

简而言之，**它削去了加速/减速造成的挤出急剧变化的"棱角"，因为这些变化现在分散到了更长的距离和时间上。** 因此，它可以减少打印速度突变时在墙上出现的瑕疵。这些瑕疵之所以出现，是因为挤出机和固件无法完全按照切片软件要求的流量挤出，尤其是在挤出速率快速变化时。

上图中可见的鼓起，是因为以高加速度和高速度打印时，被要求为悬垂减速，而挤出机无法足够快地响应所需的速度变化。

在上面的情形中，打印机（拓竹 X1 Carbon）被要求以 5k/sec² 的加速度从 200mm/sec 的打印速度降到 40mm/sec。**挤出机跟不上压力变化，结果在速度变化点的前方出现了一个轻微的凸起。**

这个参数与以下打印机运动学设置和物理限制相互作用：

1. **挤出系统的极限**——它能多快地改变喷嘴内的压力
2. **配置的压力提前值**——它同样影响喷嘴内的压力变化
3. **打印机的加速度配置**——加速度越高，压力变化越大
4. **压力提前平滑时间（Klipper）**——平滑时间越长，与理想挤出的偏差越大，这项功能能发挥作用的空间也就越大。

### 加速度与平滑挤出率

打印机的运动系统并不会完全按照 OrcaSlicer G-code 预览界面中看到的速度变化来运动。

当要求改变速度时，固件的前瞻规划器会计算达到目标速度所需的减速过程。减速的快慢受该段移动的加速度值限制。

**我们来看一个例子。** 假设以 **2k 的外墙加速度**打印一面悬垂墙，打印机需要从 **200mm/sec 减速到 40mm/sec**。

这段减速移动大约发生在 9.6mm 的距离内，由以下公式得出：

$$
d = \frac{v_f^2 - v_i^2}{2a}
$$

其中：

- vf = 最终速度。
- vi = 初始速度。
- a = 加速度（这里为负值，因为是减速）。
- d = 距离。

减速到新速度所需的时间约为 0.08 秒，由以下公式得出：

$$
t = \frac{v_f - v_i}{a}
$$

以 200mm/sec、线宽 0.42、层高 0.16 打印时，塑料的挤出量约为 12.16mm³/sec，下图也能看出这一点。

{{I3}}

以 40mm/sec、相同线宽和层高挤出时，流量为 2.43mm³/sec。

所以在这个例子中，我们要求挤出机**在 0.08 秒内把流量从 12.16mm³/sec 降到 2.43mm³/sec**，即挤出变化率为 121mm³/sec²。

**这个值与打印机的加速度成正比。加速度为 4k 时它翻倍，为 1k 时减半，而与移动速度或起止速度无关。**

**这个值还与线宽成正比——线宽加倍，挤出变化率也加倍，反之亦然。层高同理。**

继续这个例子，2k 加速度产生的挤出变化率坡度为 121mm³/sec²。**因此，设置高于这个值的 ERS 不会给打印质量带来任何好处，因为运动系统按其加速度设置本身就会以更平缓的方式减速。**

**所以，加速度值构成了这个设置的一个有实际意义的上限。** 本页后面给出了一组参考数值。

### 压力提前与平滑挤出率

接下来还需要考虑压力提前和平滑时间这两个影响挤出速率的因素。

**压力提前（Pressure Advance）** 会调整挤出机的速度，以补偿热端熔融区内的压力变化。打印头移动并挤出耗材时，由于热端内熔融塑料的可压缩性，挤出齿轮的运动与塑料实际被挤出之间存在延迟。这种延迟可能导致打印头开始移动时挤出过多、停止时挤出不足，从而出现溢料疙瘩或挤出不足等问题。

**压力提前平滑时间（Smooth time）** 有助于缓解由压力提前算法控制的挤出流量快速变化对打印质量的负面影响。这个参数本质上是给压力提前所做的调整加上平滑效果，以避免挤出速率的急剧或突然变化。

当压力提前调整挤出机速度来补偿热端内压力的增减时，可能导致流量突变。这些突变可能引发以下问题：

1. 挤出电机丢步，
2. 挤出齿轮和耗材丝磨损加剧，
3. 挤出不均匀，在打印表面形成可见的瑕疵。

平滑时间设置引入了一个受控的延迟，把压力提前的调整分散到这段时间内。这样挤出压力的施加或减小就更平缓，耗材流动的过渡也更平滑。

代价是挤出精度。由于这种平滑，要求的挤出量与实际挤出量之间会存在偏差。

**1. 增加平滑时间：** 挤出压力的变化更平缓。虽然这能减少瑕疵、减轻挤出系统的负担，但设得太高可能削弱压力提前的效果，因为补偿变得过于滞后，无法准确抵消压力变化。

**2. 减少平滑时间：** 压力提前的调整更及时，可以提高压力补偿的响应速度，但也可能重新引入流量突变，导致上面提到的问题。

本质上，**压力提前平滑时间是有意让挤出机转动（进而挤出量）偏离理想值**，好让挤出机在其机械极限内工作。这个值通常设为 0.04sec，意思是当压力提前为补偿热端内的压力变化而调整挤出流量时，这些调整会分散在 0.04 秒内完成。

[这篇 Klipper 论坛帖子]({{L2}})中有一个很好的例子，展示了压力提前平滑时间造成的偏差，值得一读，能更深入地理解这种取舍。

在上面的例子中，**我们需要把平滑挤出率设得足够低，以减小压力提前平滑时间相对于输出流量所引入的误差。** 平滑挤出率越低，流量随时间的变化越小，平滑时间算法造成的与理想挤出之间的绝对偏差也越小。但设得太低会显著降低整体打印速度，因为为了让各特征之间的挤出偏差很小，打印速度会被大幅降低，而过了某个点之后就没有实际好处了。

**找到有益的下限，最好的办法是实验。** 打印一个带有尖锐悬垂、会因悬垂速度设置而降速的物体，观察是否存在挤出不一致。

## 找到理想的平滑挤出率

**首先，这个值必须低于打印机加速度配置所产生的挤出变化率。** 由于影响通常最大的是外墙表面，请以外墙加速度作为参考。

**以下是线宽 0.42、层高 0.16 时的一些近似 ERS 值。**

1. 0.5k 加速度：30mm³/sec²
2. 1k 加速度：60.5mm³/sec²
3. 2k 加速度：121mm³/sec²
4. 4k 加速度：242mm³/sec²

**以下是线宽 0.42、层高 0.20 时的一些近似 ERS 值。**

1. 0.5k 加速度：38mm³/sec²
2. 1k 加速度：76mm³/sec²
3. 2k 加速度：150mm³/sec²
4. 4k 加速度：300mm³/sec²

**以下是线宽 0.45、层高 0.16 时的一些近似 ERS 值。**

1. 0.5k 加速度：32mm³/sec²
2. 1k 加速度：65mm³/sec²
3. 2k 加速度：129mm³/sec²
4. 4k 加速度：260mm³/sec²

**所以，调校的起点必须是比这些值更小的 ERS 值。** 测试打印的一个不错起点是上述最大值的 **60-80%**。这能为压力提前提供有意义的帮助，减小压力提前平滑时间引入的偏差。平滑时间越长，质量上的收益越大。

因此，对于**线宽 0.42、层高 0.16**，推荐的 ERS 起始值如下：

1. 0.5k 加速度：18-25mm³/sec²
2. 1k 加速度：35-50mm³/sec²
3. 2k 加速度：70-100mm³/sec²
4. 4k 加速度：145-200mm³/sec²

如果以 0.2 层高打印，可以把这些值提高 25%；层高更低时则相应降低。

**第二个因素是挤出机的机械能力。** 对耗材夹持良好的近程挤出机，通常对挤出速率变化的响应更快；较硬的耗材也是如此。因此，在远程挤出机打印机上，或打印 TPU、PolyTerra 这类软质 PLA 等较软的材料时，挤出机更有可能因为机械夹持、材料变形，或者仅仅是压力变化传递的延迟（远程结构中）而打滑或偏离期望的挤出量。

**最后一个因素是压力提前平滑时间**（或闭源固件中的等效机制）**引入的偏差。** 这个值越高，挤出与理想值的偏差越大。如果你使用近程挤出机，在调校 ERS 之前，先在 Klipper 固件中把这个值降到 0.02，因为值越低，需要缓解的偏差就越小。然后再通过实验调校 ERS。

**那么结论是什么？**

以上面的 ERS 设置为起点做一次测试打印，然后按你的喜好调整！如果在速度发生变化的尖锐悬垂处（比如 Benchy 的船身）发现鼓起，就把这个值降低 10% 再试。

如果没有发现任何瑕疵，就提高 10%，但不要超过上面推荐的最大值，否则这项功能对打印就不起作用了。

## 关于使用 Marlin 且没有压力提前的远程挤出打印机

如果你的打印机没有压力提前，尤其是使用远程挤出结构时，就无法享受压力提前动态调整流量的好处。

在这种特殊情况下，ERS 要承担压力提前通常所做的全部工作。这时通常建议使用 8-10mm³/sec² 的较低值（与加速度设置无关），在不过多影响打印速度的前提下，尽可能平滑挤出系统中的压力变化。

## 关于 ERS 分段长度

默认值 3 在大多数情况下都很好用，所以从它开始。

较低的值让每次速度过渡之间有更多的台阶，过渡更平滑。但这可能导致 G-code 过大，每秒发送给 MCU 的命令过多，MCU 可能跟不上。它还会拖慢 OrcaSlicer 前端，因为切片后的模型渲染起来更复杂。

如果想要更平滑的过渡，可以降低它，最低可到 0.5。Klipper 打印机通常能很好地处理 1 的分段长度，因为树莓派之类的上位机有足够的算力处理大量 G-code 命令，拓竹打印机通常也可以。**但如果你发现打印机卡顿或停顿**（性能较弱的 P1 系列打印机可能会这样），**或者在 Klipper 中出现"Timer too close"错误**，**就提高这个值**，回到默认的 3 或更高（最高 5）。这会降低这个设置的效果，但能让打印机的负载更可控。

## 仅应用于外部特征

{{M2}}
只对外墙和悬垂墙应用平滑挤出率，其他所有特征的流量保持不变。这样可以减少可见悬垂处急剧的速度过渡造成的瑕疵，而不会拖慢那些看不见的特征。  
只有平滑挤出率大于 0 时才会显示这个选项，默认禁用。

## 局限

**这项功能只在速度变化由切片软件引起的地方起作用**——例如打印悬垂、桥接时从快速移动过渡到慢速移动，以及从打印内部特征过渡到外部特征（或反过来）时。

但当打印机因固件命令而减速时（例如过转角时），它不会影响挤出机的行为。

在这种情况下，打印机会自行减速再加速，与切片软件的要求无关。切片软件下达的是恒定速度，但打印机会按照其运动学限制（SCV/抖动）和加速度来调整速度。由于切片软件并不知道这次减速，它就无法对该特征预先进行挤出速率平滑，这时的变化完全由打印机固件控制。
