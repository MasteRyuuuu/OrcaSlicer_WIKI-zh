# 首层速度

首层比打印件的其余部分打印得更慢，这是被广泛推荐的做法。这有助于确保与打印床牢固附着，降低边缘翘曲或卷边的几率，并能更好地弥补轻微的调平不一致。

## 首层

{{M1}}
这个设置决定首层上[外墙/内墙]({{L1}})以及 Brim 的打印速度。  
首层的其他所有挤出，例如[实心填充]({{L2}})，以及[底部层数]({{L4}})设为 0 时打印的[稀疏填充]({{L3}})，都使用[首层填充]({{L5}})速度。  
调整这个速度有助于确保首层的附着和打印质量。

## 首层填充

{{M2}}
定义首层上除墙和 Brim 以外所有内容（主要是[实心填充]({{L6}})区域）的速度。这些区域需要更精确、更稳定的挤出，为后续各层打下平整稳固的基础。这部分打印得太快可能导致内部应力过高（翘曲风险增加）、层的均匀性差或附着失败。

## 首层空驶速度

{{M3}}
设置首层的空驶（不打印的移动）速度。它不影响打印质量，可以设为[空驶速度]({{L7}})的百分比。  
通常设为[空驶速度]({{L8}})的 100%；如果你想减少振动，或者打印机在高速空驶时有问题，也可以降低它。

## 慢速层数量

{{M4}}
指定最初的多少层以较低的速度打印。首层之后不会直接跳到全速，而是在这些层内按线性方式逐渐提速。这种逐步提速有助于保持附着，让打印件在早期阶段更稳定，对于接触面积小的打印件或容易翘曲的材料尤其如此。
