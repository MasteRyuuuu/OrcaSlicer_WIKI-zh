# Filament for Features

These settings allow you to specify which filament to use for different features of the print, such as walls, infill, and the wipe tower.

## Outer Walls

{{M1}}
Filament to print outer walls.  
You can also print the outer walls with a translucent filament to achieve a frosted glass effect.  
When using a [mixed nozzle size setup]({{L1}}), it's recommended to use the smaller nozzle for outer walls to achieve better surface quality and detail.

## Inner Walls

{{M2}}
Filament to print inner walls.  
When using a [mixed nozzle size setup]({{L2}}), you can use a larger nozzle for inner walls to speed up printing while maintaining good layer adhesion.

## Sparse Infill

{{M3}}
Filament to print internal sparse infill.  
When using a [mixed nozzle size setup]({{L3}}), you can use a larger nozzle for infill to speed up printing while maintaining good layer adhesion.

## Internal Solid Infill

{{M4}}
Filament to print internal solid infill.  
When using a [mixed nozzle size setup]({{L4}}), you can use a larger nozzle for internal solid infill to speed up printing while maintaining good layer adhesion.

## Top Surface

{{M5}}
Filament to print top surfaces.  
It's recommended to use the same filament for top surfaces as for outer walls to achieve a consistent appearance.  
When using a [mixed nozzle size setup]({{L5}}), it's recommended to use the smaller nozzle for top surfaces to achieve better surface quality and detail.

## Bottom Surface

{{M6}}
Filament to print bottom surfaces.  
You can use a different filament for the bottom surfaces, such as a more adhesive one to improve bed adhesion.  
When using a [mixed nozzle size setup]({{L6}}), you can use a larger nozzle for bottom surfaces to speed up printing while maintaining good layer adhesion.

## Wipe Tower

{{M7}}
Filament to print the perimeter of the wipe tower. Set to `Default` to use any available filament, preferring a non-soluble one.
