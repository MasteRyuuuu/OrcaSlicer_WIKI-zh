# Releases

Release notes for each version of OrcaSlicer, newest first. Select a version to read the full changelog.

## History

> [!NOTE]
> A stable release includes every feature from its earlier alpha and beta builds, but the stable changelog only lists what changed since the last stable release — it does not repeat those alpha and beta features.  
> To see everything new between one stable release and the next, read the accompanying alpha and beta notes as well.

- **[V2.5.0 Alpha]({{L1}})** — The most feature-packed release yet: Python plugins, belt printing, the experimental Design tab, color mixing, Texture Displacement, and IDEX/IQEX parallel printing.
- **[V2.4.2]({{L2}})** — Maintenance update focused on more dependable profiles, cloud sync, and printer connectivity, plus several crash fixes.
- **[V2.4.1]({{L3}})** — Maintenance update with a broad round of profile and preset fixes, a native Windows ARM64 build, and a reworked skirt and brim generator.
- **[V2.4.0]({{L4}})** — Bug fixes, a smoother Orca Cloud experience, and the ability to send sliced jobs to the printer as a packaged 3MF.
    - **[V2.4.0 Beta]({{L5}})** — Stability, speed, and print-quality work — greatly improved bridging and a new realistic rendering option.
    - **[V2.4.0 Alpha]({{L6}})** — Introduces Orca Cloud (profile sync and sharing), Z Anti-Aliasing contouring, an Expert user mode, and native Wayland support for Linux.
