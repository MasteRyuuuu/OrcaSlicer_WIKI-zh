# Prepare Toolbar

{{T1}}

## Add Objects

Choose one or more files (3MF/STEP/STL/SVG/OBJ/AMF) to import into the current project as [Object Sets]({{L1}}).  

> [!TIP]
> See [Import and Export]({{L2}}) for more information about supported file formats and import methods.

## Add Plate

Adds a new print plate to the current project.

## Measure Tool

Use the Measure Tool to measure distances between points/edges/faces on your 3D model.
